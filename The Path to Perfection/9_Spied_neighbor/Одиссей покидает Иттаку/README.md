# Transportation LP — транспортная задача (метод потенциалов)

Единая модель линейного программирования:

    min  Z = Σ c_ij · x_ij
    s.t. Σ_j x_ij = a_i        (вывоз всего запаса)
         Σ_i x_ij = b_j        (удовлетворение спроса)
         x_ij ≥ 0

Решение: **метод потенциалов** (двойственные переменные u_i, v_j).
Критерий оптимальности: Δ_ij = c_ij − u_i − v_j ≥ 0 для всех клеток.
